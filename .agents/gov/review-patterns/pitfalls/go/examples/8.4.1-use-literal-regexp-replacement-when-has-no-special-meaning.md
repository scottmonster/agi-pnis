# Use literal regexp replacement when `$` has no special meaning

## 1. Catalog record

- **Catalog identifier:** 8.4.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `ReplaceAllLiteralString` when the replacement text is literal. `ReplaceAllString` interprets `$name` and `$1` forms as capture expansion.

## 2. Example

### 2.1 Scenario

A notification formatter replaces a placeholder with a customer-provided amount such as `$100`.

### 2.2 Preferred form

```go
package notice

import "regexp"

var amountSlot = regexp.MustCompile(`\{amount\}`)

func render(template, amount string) string {
	return amountSlot.ReplaceAllLiteralString(template, amount)
}
```

### 2.3 Hazardous form

```go
package notice

import "regexp"

var amountSlot = regexp.MustCompile(`\{amount\}`)

func render(template, amount string) string {
	return amountSlot.ReplaceAllString(template, amount)
}
```

### 2.4 Why this difference matters

The regular replacement method interprets dollar sequences as capture references. A literal value such as `$100` can be changed unexpectedly or disappear when the expression has no matching capture.

## 3. Boundaries and distinctions

Use `ReplaceAllString` when the replacement intentionally includes capture expansion, such as `$1`. For literal replacement text, the literal method is clearer even when current values contain no dollar signs.
