# Using `strip()` to remove a literal prefix or suffix

## 1. Catalog record

- **Catalog identifier:** 8.7.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `removeprefix()` or `removesuffix()` for literal affixes rather than `lstrip()`, `rstrip()`, or `strip(chars)`.

## 2. Example

### 2.1 Scenario

A command parser removes the literal `cmd:` prefix from user input.

### 2.2 Preferred form

```python
command = "cmd:commit"
name = command.removeprefix("cmd:")

assert name == "commit"
```

### 2.3 Hazardous form

```python
command = "cmd:commit"
name = command.lstrip("cmd:")

assert name == "ommit"
```

### 2.4 Why this difference matters

`lstrip()` treats its argument as a set of removable characters, not as one literal prefix.

## 3. Boundaries and distinctions

Use `strip()` when trimming a set of delimiter or whitespace characters is actually intended.
