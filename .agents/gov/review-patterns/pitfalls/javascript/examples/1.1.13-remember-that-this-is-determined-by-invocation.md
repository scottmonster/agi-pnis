# Remember that this is determined by invocation

## 1. Catalog record

- **Catalog identifier:** 1.1.13
- **Impact:** medium
- **Consensus:** high
- **Definition:** For ordinary functions, `this` generally depends on how the function is called, not where it was defined or which object originally stored it.

## 2. Example

### 2.1 Scenario

A counter exposes an ordinary method that updates its own state.

### 2.2 Preferred form

```javascript
"use strict";

const counter = {
  value: 0,
  increment() {
    this.value += 1;
    return this.value;
  },
};

console.log(counter.increment());
```

### 2.3 Hazardous form

```javascript
"use strict";

const counter = {
  value: 0,
  increment() {
    this.value += 1;
    return this.value;
  },
};

const increment = counter.increment;
console.log(increment());
```

### 2.4 Why this difference matters

Extracting the method removes its receiver. In strict mode, the bare call has `undefined` for `this` and fails when it accesses `value`.

## 3. Boundaries and distinctions

Arrow functions capture lexical `this` instead. Use them only when that fixed receiver behavior is the intended contract.
