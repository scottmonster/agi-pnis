# Use Unicode-aware regex semantics for Unicode text

## 1. Catalog record

- **Catalog identifier:** 5.1.8
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use the `u` or, where appropriate, `v` flag when patterns are intended to operate on Unicode code points or Unicode properties rather than legacy UTF-16 behavior. Do not assume `\w` means every Unicode letter.

## 2. Example

### 2.1 Scenario

An account service accepts names written in many scripts.

### 2.2 Preferred form

```javascript
function isLetterName(value) {
  return /^\p{L}+$/u.test(value);
}

console.log(isLetterName("Åsa")); // true
console.log(isLetterName("李")); // true
```

### 2.3 Hazardous form

```javascript
function isLetterName(value) {
  return /^\w+$/.test(value);
}

console.log(isLetterName("李")); // false
```

### 2.4 Why this difference matters

The hazardous ASCII-oriented class excludes many valid letters, producing incorrect validation for international names.

## 3. Boundaries and distinctions

Unicode-aware flags do not make every pattern linguistically correct. Define whether digits, marks, spaces, normalization, and script-mixing are valid for the specific domain.
