# Use nullish coalescing for nullish defaults

## 1. Catalog record

- **Catalog identifier:** 1.1.4
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `value ?? fallback` when `0`, `false`, and `""` are valid values. Use `||` only when every falsy value should trigger the fallback.

## 2. Example

### 2.1 Scenario

A report may specify zero visible rows, which is a valid setting.

### 2.2 Preferred form

```javascript
function visibleRows(requestedRows) {
  return requestedRows ?? 25;
}

console.log(visibleRows(0));
```

### 2.3 Hazardous form

```javascript
function visibleRows(requestedRows) {
  return requestedRows || 25;
}

console.log(visibleRows(0));
```

### 2.4 Why this difference matters

`||` treats zero as absent and changes the caller's explicit choice to 25, while `??` defaults only nullish values.

## 3. Boundaries and distinctions

Use `||` when every falsy value, including zero and an empty string, should intentionally select the fallback.
