# Absolute components resetting `os.path.join()`

## 1. Catalog record

- **Catalog identifier:** 15.1.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Validate path components when joining untrusted or assumed-relative values. Do not assume appending an absolute component keeps the preceding base path.

## 2. Example

### 2.1 Scenario

A service stores a user-selected export filename beneath its configured export directory. The filename must be a relative path component.

### 2.2 Preferred form

```python
from pathlib import Path


def export_path(base: Path, requested_name: str) -> Path:
    candidate = Path(requested_name)
    if candidate.is_absolute():
        raise ValueError("export name must be relative")
    return base / candidate
```

### 2.3 Hazardous form

```python
import os


def export_path(base: str, requested_name: str) -> str:
    return os.path.join(base, requested_name)
```

### 2.4 Why this difference matters

If `requested_name` is absolute, `os.path.join()` discards `base`. An attacker or configuration mistake can therefore redirect output outside the export directory.

## 3. Boundaries and distinctions

Absolute components are valid when callers deliberately choose a complete destination. Validate containment too when relative paths may contain traversal components.
