# Prefer `??` to `||` for nullish defaults

## 1. Catalog record

- **Catalog identifier:** 6.4.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use nullish coalescing when the fallback should apply only to `null` or `undefined`.

## 2. Example

### 2.1 Scenario

A retry option accepts zero as a deliberate configuration value.

### 2.2 Preferred form

```typescript
function retriesFor(configured: number | undefined): number {
  return configured ?? 3;
}

```

### 2.3 Hazardous form

```typescript
function retriesFor(configured: number | undefined): number {
  return configured || 3; // Changes an explicit zero to three.
}
```

### 2.4 Why this difference matters

`||` also replaces valid falsy values such as `0`, `false`, and empty strings.

## 3. Boundaries and distinctions

Apply this guidance in the conditions described by the catalog record. Deliberate exceptions need a documented runtime guarantee, compatible toolchain behavior, or an explicit local unsafe boundary.
