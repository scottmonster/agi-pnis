# Save `$!` immediately for each asynchronous job

## 1. Catalog record

- **Catalog identifier:** 8.11.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** `$!` identifies the most recently started asynchronous process or applicable process substitution, so store it before launching another asynchronous operation.

## 2. Example

### 2.1 Scenario

A script starts two independent background tasks and must wait for both.

### 2.2 Preferred form

```bash
generate_report() { sleep 1; }
upload_report() { sleep 1; }

generate_report &
generate_pid=$!
upload_report &
upload_pid=$!

wait "$generate_pid"
wait "$upload_pid"
```

### 2.3 Hazardous form

```bash
generate_report() { sleep 1; }
upload_report() { sleep 1; }

generate_report &
upload_report &
worker_pid=$!

wait "$worker_pid"
```

### 2.4 Why this difference matters

Each new asynchronous launch replaces `$!`. The hazardous form retains only the upload process identifier and can finish without waiting for report generation.

## 3. Boundaries and distinctions

`$!` refers to the most recent applicable asynchronous process in the current shell. A job-control interface may be useful interactively, but scripts should retain explicit process identifiers.
