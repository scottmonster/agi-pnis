# Unmarshalling untrusted data

## 1. Catalog record

- **Catalog identifier:** 2.1.3
- **Impact:** high
- **Consensus:** high
- **Definition:** Do not use `marshal` as a general-purpose or untrusted serialization format.

## 2. Example

### 2.1 Scenario

A cache importer reads records that another service supplied.

### 2.2 Preferred form

```python
import json


def load_record(payload: bytes) -> dict[str, int]:
    record = json.loads(payload)
    if not isinstance(record, dict):
        raise ValueError("record must be an object")
    return record


print(load_record(b'{"attempts": 3}'))
```

### 2.3 Hazardous form

```python
import marshal


def load_record(payload: bytes) -> object:
    return marshal.loads(payload)


received_payload = b"untrusted bytes"
print(load_record(received_payload))
```

### 2.4 Why this difference matters

Marshal is an implementation detail with no stable general data contract and is not appropriate for untrusted input.

## 3. Boundaries and distinctions

Marshal can support specialized Python-internal uses such as bytecode caches, but application data should use a specified and validated interchange format.
