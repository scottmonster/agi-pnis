# Incomplete generation

## 1. Catalog record

- **Catalog identifier:** 6.11
- **Evidence:** e
- **Definition:** Function/class/file ends before the requested behavior exists.

## 2. Scenario

### 2.1 Context

The requested export feature must collect records, write CSV output, and return the download path.

### 2.2 Safer approach

The agent traces each requested step and exercises the completed export flow.

### 2.3 Failure mode

It adds record collection and starts the writer function but leaves before writing or returning the file.

### 2.4 Why this difference matters

The requested feature's essential behavior never becomes available.

## 3. Boundaries and distinctions

Incomplete generation stops before behavior exists; an empty or constant implementation supplies a stub that still does no meaningful computation.
