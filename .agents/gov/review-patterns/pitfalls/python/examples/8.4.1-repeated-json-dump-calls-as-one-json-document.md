# Repeated `json.dump()` calls as one JSON document

## 1. Catalog record

- **Catalog identifier:** 8.4.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Do not append multiple independent `json.dump()` outputs to one stream and expect the result to be a valid single JSON document. Use an explicit framing format or outer collection.

## 2. Example

### 2.1 Scenario

A service writes two audit records to a file that another program will load as one JSON document.

### 2.2 Preferred form

```python
import json
from pathlib import Path

records = [{"event": "created"}, {"event": "approved"}]
path = Path("audit.json")
path.write_text(json.dumps(records), encoding="utf-8")

assert json.loads(path.read_text(encoding="utf-8")) == records
```

### 2.3 Hazardous form

```python
import json
import io

stream = io.StringIO()
json.dump({"event": "created"}, stream)
json.dump({"event": "approved"}, stream)

invalid_document = stream.getvalue()
assert invalid_document == '{"event": "created"}{"event": "approved"}'
```

### 2.4 Why this difference matters

Adjacent JSON values have no framing in a normal JSON document, so a standard decoder rejects the output.

## 3. Boundaries and distinctions

Newline-delimited JSON or another documented record framing format can intentionally contain multiple JSON values.
