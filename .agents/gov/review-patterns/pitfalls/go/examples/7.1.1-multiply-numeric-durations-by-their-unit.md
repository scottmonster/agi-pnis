# Multiply numeric durations by their unit

## 1. Catalog record

- **Catalog identifier:** 7.1.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Write `time.Duration(n) * time.Second` or another explicit unit instead of converting a unitless integer and assuming seconds or milliseconds.

## 2. Example

### 2.1 Scenario

A worker configuration supplies a timeout as a whole number of seconds.

### 2.2 Preferred form

```go
package worker

import "time"

func timeout(seconds int) time.Duration {
	return time.Duration(seconds) * time.Second
}
```

### 2.3 Hazardous form

```go
package worker

import "time"

func timeout(seconds int) time.Duration {
	return time.Duration(seconds) // Interpreted as nanoseconds.
}
```

### 2.4 Why this difference matters

The hazardous timeout of `30` lasts 30 nanoseconds, not 30 seconds, which can make requests fail immediately.

## 3. Boundaries and distinctions

A direct conversion is correct only when the input is already specified in nanoseconds.
