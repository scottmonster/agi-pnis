# Lexical parent walking without resolving symlinks

## 1. Catalog record

- **Catalog identifier:** 15.2.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** When traversing upward through an arbitrary filesystem path and symlink identity matters, resolve the path before performing lexical parent operations.

## 2. Example

### 2.1 Scenario

A deployment utility needs the actual project root containing a file that may have been reached through a symlink.

### 2.2 Preferred form

```python
from pathlib import Path


def project_root(file_path: Path) -> Path:
    return file_path.resolve().parent
```

### 2.3 Hazardous form

```python
from pathlib import Path


def project_root(file_path: Path) -> Path:
    return file_path.parent
```

### 2.4 Why this difference matters

The hazardous version walks the spelling of the path, not its filesystem target. A symlink can make that lexical parent different from the directory that actually contains the file.

## 3. Boundaries and distinctions

Avoid resolution when preserving a user-entered path spelling is the goal, or when a missing target is expected. Resolve when filesystem identity and symlink traversal affect the operation.
