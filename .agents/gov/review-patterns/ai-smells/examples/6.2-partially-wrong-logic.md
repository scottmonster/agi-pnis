# Partially wrong logic

## 1. Catalog record

- **Catalog identifier:** 6.2
- **Evidence:** e
- **Definition:** Works for many inputs but violates part of the specification.

## 2. Scenario

### 2.1 Context

An endpoint must return invoices visible to both an account owner and authorized delegates.

### 2.2 Safer approach

The agent implements both visibility paths and tests each role.

### 2.3 Failure mode

It returns invoices for the owner but omits delegates.

### 2.4 Why this difference matters

Common requests pass while a required part of the contract remains unavailable.

## 3. Boundaries and distinctions

The logic has a valid result for some supported inputs; completely wrong logic produces the wrong result for the intended task itself.
