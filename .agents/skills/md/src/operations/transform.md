# Transform

Transform a specified Markdown source scope into a new or revised target while preserving materially equivalent meaning and intended use.

Require `../rules/preservation.md`

## Boundary and destination

Read the complete source and directly referenced material needed to interpret it. Identify the intended consumer, consumption model, dependencies, exact compatibility-sensitive literals, and preservation boundary.

Establish the equivalence boundary before restructuring: identify intended outcomes, intended consumers, consumption and retrieval patterns, point-of-use access needs, externally depended-on structures, and observable success criteria.

Honor the requested destination. Do not overwrite a source unless the request clearly calls for editing or replacing it. If a local transformation request has no destination, create a sibling file using `.low` or `.high`, based on the normalized compression level, before the original extension.

## Authorized redesign

You may improve wording, grouping, order, or formatting only when meaning is unchanged.
