# Prefer strict equality when coercion is not intentional

## 1. Catalog record

- **Catalog identifier:** 1.1.3
- **Impact:** medium
- **Consensus:** high
- **Definition:** Prefer `===` and `!==` for ordinary comparisons. Use `==` only when its coercion behavior is deliberate, such as the compact `value == null` check for both `null` and `undefined`.

## 2. Example

### 2.1 Scenario

An API accepts a numeric account identifier and must reject text that only looks numeric.

### 2.2 Preferred form

```javascript
function isAdminAccount(accountId) {
  return accountId === 1;
}

console.log(isAdminAccount("1"));
```

### 2.3 Hazardous form

```javascript
function isAdminAccount(accountId) {
  return accountId == 1;
}

console.log(isAdminAccount("1"));
```

### 2.4 Why this difference matters

The loose comparison coerces the string into a number and accepts input that did not meet the function's numeric contract.

## 3. Boundaries and distinctions

Loose equality can be deliberate, notably `value == null` when both nullish values should match. Use it only when that coercion is part of the documented behavior.
