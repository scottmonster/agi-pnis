# Ordinary equality for secret digests

## 1. Catalog record

- **Catalog identifier:** 2.10.1
- **Impact:** high
- **Consensus:** high
- **Definition:** When verifying an externally supplied HMAC or similar secret-dependent digest, use `hmac.compare_digest()` or `secrets.compare_digest()` rather than `==`.

## 2. Example

### 2.1 Scenario

A webhook endpoint verifies the signature supplied by a sender against a locally computed HMAC.

### 2.2 Preferred form

```python
import hashlib
import hmac


def signature_is_valid(body: bytes, supplied: str, key: bytes) -> bool:
    expected = hmac.new(key, body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, supplied)
```

### 2.3 Hazardous form

```python
import hashlib
import hmac


def signature_is_valid(body: bytes, supplied: str, key: bytes) -> bool:
    expected = hmac.new(key, body, hashlib.sha256).hexdigest()
    return expected == supplied
```

### 2.4 Why this difference matters

Ordinary equality may reveal timing information about how much of a secret-dependent value matched. `compare_digest()` is designed for this comparison.

## 3. Boundaries and distinctions

This matters for secret-dependent values exposed to an attacker. Ordinary equality is appropriate for ordinary non-secret application data.
