# Remember that globs are expanded before `sudo`

## 1. Catalog record

- **Catalog identifier:** 3.12.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Perform protected pathname discovery in the privileged context when glob expansion needs privileged access.

## 2. Example

### 2.1 Scenario

An administrator needs to remove archived logs from a directory that only root can traverse.

### 2.2 Preferred form

```bash
sudo find /var/private-logs -type f -name '*.old' -delete
```

### 2.3 Hazardous form

```bash
sudo rm /var/private-logs/*.old
```

### 2.4 Why this difference matters

The invoking shell expands `*.old` before `sudo` starts `rm`. A user who cannot inspect the directory cannot produce the intended argument list.

## 3. Boundaries and distinctions

Using a glob with `sudo` is fine when the invoking shell can safely expand the intended paths and those semantics are desired.
