# Build and Maintain the Go Pitfalls Catalog Family

Run this workflow independently for Go only. Apply the shared [language pitfalls workflow](pitfalls.md) in full.

```text
Historical input: ../sources/pitfalls-go/go.md
Catalog: ../../pitfalls/go/go-pitfalls-catalog.md
Rules: ../../pitfalls/go/go-pitfalls-rules.md
Examples: ../../pitfalls/go/examples/
Sources: ../sources/pitfalls-go.md
```

Research the Go language, memory model, standard library, runtime, modules and workspaces, tooling, concurrency, security, and established development practice. Prefer the Go specification, official package documentation, release notes, Go blog and developer guidance, and official security documentation. Record Go-version, operating-system, architecture, standard-library, and toolchain limits precisely.

Use `# Go Pitfalls Catalog` and `# Go Pitfalls Rules` as the derived-file titles.
