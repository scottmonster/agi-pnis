# Know Math.round's negative-half behavior

## 1. Catalog record

- **Catalog identifier:** 4.1.13
- **Impact:** low
- **Consensus:** high
- **Definition:** Do not assume `Math.round()` is equivalent to a language-independent "round away from zero" rule. Halfway cases are rounded toward positive infinity and can produce negative zero.

## 2. Example

### 2.1 Scenario

A billing rule requires midpoint values to round away from zero.

### 2.2 Preferred form

```javascript
function roundAwayFromZero(value) {
  return value < 0 ? -Math.round(-value) : Math.round(value);
}

console.log(roundAwayFromZero(-1.5));
```

### 2.3 Hazardous form

```javascript
function roundAwayFromZero(value) {
  return Math.round(value);
}

console.log(roundAwayFromZero(-1.5));
```

### 2.4 Why this difference matters

`Math.round(-1.5)` is `-1`, because JavaScript rounds halfway values toward positive infinity rather than away from zero.

## 3. Boundaries and distinctions

`Math.round()` is correct when its specified behavior matches the domain rule. Financial and other policy-sensitive rounding may require an explicitly chosen algorithm.
