# File moves mixed into an unrelated fix

## 1. Catalog record

- **Catalog identifier:** 11.5
- **Evidence:** se
- **Definition:** Relocates files while changing behavior, complicating history, review, and conflict resolution without need.

## 2. Scenario

### 2.1 Context

A bug report says CSV imports mishandle quoted commas.

### 2.2 Safer approach

The agent corrects the parser in its current module and adds a fixture covering quoted fields.

### 2.3 Failure mode

The agent moves the parser and its tests to a new directory while changing quote handling, although the move is not needed.

### 2.4 Why this difference matters

Git history and review become harder to follow, and concurrent changes are more likely to conflict.

## 3. Boundaries and distinctions

A move is warranted when required by a new architecture or build rule; the problem is an unnecessary relocation combined with a behavior fix.
