# Using `commonprefix()` for path containment

## 1. Catalog record

- **Catalog identifier:** 2.17.2
- **Impact:** high
- **Consensus:** high
- **Definition:** Do not use `os.path.commonprefix()` to decide whether one filesystem path is contained by another. Use path-aware canonicalization and `commonpath()` or equivalent containment logic.

## 2. Example

### 2.1 Scenario

A file-download service must accept paths only inside a configured export directory.

### 2.2 Preferred form

```python
from pathlib import Path


def is_under_export(candidate: Path, export_dir: Path) -> bool:
    try:
        candidate.resolve().relative_to(export_dir.resolve())
    except ValueError:
        return False
    return True
```

### 2.3 Hazardous form

```python
import os
from pathlib import Path


def is_under_export(candidate: Path, export_dir: Path) -> bool:
    return os.path.commonprefix([str(candidate), str(export_dir)]) == str(export_dir)
```

### 2.4 Why this difference matters

`commonprefix()` compares characters, so `/exports-private` can appear to be inside `/exports`. Path-aware containment compares path components instead.

## 3. Boundaries and distinctions

Resolve paths when containment must account for symlinks. Lexical comparisons can be appropriate only when that distinction is explicitly irrelevant.
