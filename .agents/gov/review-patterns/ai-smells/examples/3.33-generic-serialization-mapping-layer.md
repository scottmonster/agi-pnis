# Generic serialization/mapping layer

## 1. Catalog record

- **Catalog identifier:** 3.33
- **Evidence:** se
- **Definition:** Adds conversion abstractions over one stable representation.

## 2. Scenario

### 2.1 Context

An API returns one stable JSON representation of an order.

### 2.2 Safer approach

Serialize the order explicitly at the API boundary with a focused test.

### 2.3 Failure mode

Create generic mapper interfaces, profiles, and conversion registries for the one JSON shape.

### 2.4 Why this difference matters

The mapping system adds indirection and configuration while hiding the only representation that matters.

## 3. Boundaries and distinctions

A mapping layer can be useful across multiple changing representations; one stable conversion may be clearer as direct code.
