# Undefined variable/function/member

## 1. Catalog record

- **Catalog identifier:** 6.7
- **Evidence:** e
- **Definition:** References a name or member that has not been declared, imported, or made available in scope.

## 2. Scenario

### 2.1 Context

A handler needs the repository's current user lookup function.

### 2.2 Safer approach

The agent searches the module exports and imports the available `findUserById` function.

### 2.3 Failure mode

It calls `getCurrentUser()` even though no such local name is declared or imported.

### 2.4 Why this difference matters

The reference fails at type checking or execution before the handler can satisfy its request.

## 3. Boundaries and distinctions

This concerns name availability in scope, rather than a real API used with invalid arguments.
