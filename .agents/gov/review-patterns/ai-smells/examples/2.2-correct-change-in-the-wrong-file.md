# Correct change in the wrong file

## 1. Catalog record

- **Catalog identifier:** 2.2
- **Evidence:** a
- **Definition:** Understands the logic but modifies a duplicate, obsolete, generated, or otherwise incorrect location.

## 2. Scenario

### 2.1 Context

A repository contains `src/templates/email.ts` and generated output under `dist/templates/email.js`.

### 2.2 Safer approach

The agent checks the build configuration and edits `src/templates/email.ts`, then rebuilds or runs the relevant test.

### 2.3 Failure mode

It fixes the generated `dist` file because the rendered text there is easy to find.

### 2.4 Why this difference matters

The apparent fix is overwritten on the next build and does not maintain the actual source of behavior.

## 3. Boundaries and distinctions

This differs from a logic error: the intended logic may be correct, but the selected file is not the authoritative location.
