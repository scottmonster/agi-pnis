# Default parameters and destructuring defaults do not replace null

## 1. Catalog record

- **Catalog identifier:** 1.1.10
- **Impact:** medium
- **Consensus:** high
- **Definition:** JavaScript parameter and destructuring defaults activate for `undefined`, not for `null`. Normalize null explicitly when null should also mean "missing."

## 2. Example

### 2.1 Scenario

A formatting helper uses ten as its default precision when callers omit the setting.

### 2.2 Preferred form

```javascript
function normalizePrecision(precision) {
  return precision ?? 10;
}

console.log(normalizePrecision(null));
```

### 2.3 Hazardous form

```javascript
function normalizePrecision(precision = 10) {
  return precision;
}

console.log(normalizePrecision(null));
```

### 2.4 Why this difference matters

The parameter default does not apply to `null`, allowing null to reach code that expects a numeric precision.

## 3. Boundaries and distinctions

Default parameters are correct when `undefined` alone means missing and `null` has a distinct semantic meaning.
