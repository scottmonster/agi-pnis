# Do not use map when you ignore its returned array

## 1. Catalog record

- **Catalog identifier:** 3.1.11
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `map()` when transforming each element into a new array. If the return values are deliberately discarded, use a loop or `forEach()` as appropriate.

## 2. Example

### 2.1 Scenario

A notification routine only sends messages and does not need a transformed collection.

### 2.2 Preferred form

```javascript
const recipients = ["Ari", "Mina"];
const sent = [];

recipients.forEach((recipient) => sent.push(`Sent to ${recipient}`));
console.log(sent); // ["Sent to Ari", "Sent to Mina"]
```

### 2.3 Hazardous form

```javascript
const recipients = ["Ari", "Mina"];
const sent = [];

recipients.map((recipient) => sent.push(`Sent to ${recipient}`));
console.log(sent); // ["Sent to Ari", "Sent to Mina"]
```

### 2.4 Why this difference matters

The hazardous form performs the side effect but also allocates and discards an array of `push` return values, obscuring the code's purpose.

## 3. Boundaries and distinctions

Use `map` when its resulting array is part of the needed outcome. `forEach` is suitable for synchronous side effects.
