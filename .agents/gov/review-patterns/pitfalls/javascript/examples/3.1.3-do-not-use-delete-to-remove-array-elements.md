# Do not use delete to remove array elements

## 1. Catalog record

- **Catalog identifier:** 3.1.3
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `splice()` or an immutable reconstruction when removing an indexed array element. `delete array[i]` removes the property but leaves the length unchanged and creates a hole.

## 2. Example

### 2.1 Scenario

A shopping list must remove an item and keep the remaining positions consecutive.

### 2.2 Preferred form

```javascript
const items = ["apples", "bread", "tea"];
items.splice(1, 1);

console.log(items); // ["apples", "tea"]
console.log(items.length); // 2
```

### 2.3 Hazardous form

```javascript
const items = ["apples", "bread", "tea"];
delete items[1];

console.log(items); // ["apples", <1 empty item>, "tea"]
console.log(items.length); // 3
```

### 2.4 Why this difference matters

`delete` removes only the indexed property, leaving a hole and the old length, so later iteration can observe unexpected positions.

## 3. Boundaries and distinctions

`delete` is useful for object properties. For arrays, use it only when a hole is the intended representation.
