# Quote `tr` ranges and decide their locale semantics

## 1. Catalog record

- **Catalog identifier:** 9.11.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Quote `tr` operands and choose character classes or a controlled locale for the intended character semantics.

## 2. Example

### 2.1 Scenario

A script normalizes ASCII identifiers to lowercase before creating resource names.

### 2.2 Preferred form

```bash
#!/usr/bin/env bash
set -euo pipefail

identifier='SERVICE_API'
lowercase=$(LC_ALL=C tr 'A-Z' 'a-z' <<< "$identifier")
printf '%s\n' "$lowercase"
```

### 2.3 Hazardous form

```bash
#!/usr/bin/env bash
set -euo pipefail

identifier='SERVICE_API'
lowercase=$(tr [A-Z] [a-z] <<< "$identifier")
printf '%s\n' "$lowercase"
```

### 2.4 Why this difference matters

Unquoted bracket expressions can be expanded by the shell, while locale-sensitive ranges may not describe the intended set of characters.

## 3. Boundaries and distinctions

Use locale-aware character classes when multilingual text is intentional, and document the chosen locale behavior.
