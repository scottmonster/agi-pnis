# Give reduce an initial value when emptiness is possible

## 1. Catalog record

- **Catalog identifier:** 3.1.12
- **Impact:** medium
- **Consensus:** high
- **Definition:** Supply an explicit initial accumulator unless the input is guaranteed non-empty and the first element is intentionally the accumulator.

## 2. Example

### 2.1 Scenario

A cart total is calculated from a filtered list that may have no qualifying prices.

### 2.2 Preferred form

```javascript
const prices = [];
const total = prices.reduce((sum, price) => sum + price, 0);

console.log(total); // 0
```

### 2.3 Hazardous form

```javascript
const prices = [];
const total = prices.reduce((sum, price) => sum + price);

console.log(total); // TypeError before this line
```

### 2.4 Why this difference matters

Without an initial accumulator, `reduce` needs a first element. An empty array has none, so it throws a `TypeError`.

## 3. Boundaries and distinctions

Omitting the initial value is valid when non-emptiness is guaranteed and the first element is intentionally the starting accumulator.
