# Do not assume standard-library output bytes remain implementation-stable

## 1. Catalog record

- **Catalog identifier:** 12.13.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Tests and protocols should depend on documented semantic output, not exact bytes from compressors, unstable sorts, or other implementations unless byte stability is explicitly promised.

## 2. Example

### 2.1 Scenario

A package compresses a payload with gzip. Its test needs to verify that consumers recover the original payload, not that a particular Go version emits one byte sequence.

### 2.2 Preferred form

```go
package example

import (
	"bytes"
	"compress/gzip"
	"io"
	"testing"
)

func gzipPayload(payload []byte) ([]byte, error) {
	var compressed bytes.Buffer
	writer := gzip.NewWriter(&compressed)
	if _, err := writer.Write(payload); err != nil {
		return nil, err
	}
	if err := writer.Close(); err != nil {
		return nil, err
	}
	return compressed.Bytes(), nil
}

func TestGzipPayload(t *testing.T) {
	want := []byte("important payload")
	compressed, err := gzipPayload(want)
	if err != nil {
		t.Fatal(err)
	}
	reader, err := gzip.NewReader(bytes.NewReader(compressed))
	if err != nil {
		t.Fatal(err)
	}
	decompressed, err := io.ReadAll(reader)
	if closeErr := reader.Close(); err == nil {
		err = closeErr
	}
	if err != nil {
		t.Fatal(err)
	}
	if !bytes.Equal(decompressed, want) {
		t.Fatalf("decompressed = %q, want %q", decompressed, want)
	}
}
```

### 2.3 Hazardous form

```go
package example

import (
	"bytes"
	"compress/gzip"
	"testing"
)

func gzipPayload(payload []byte) ([]byte, error) {
	var compressed bytes.Buffer
	writer := gzip.NewWriter(&compressed)
	if _, err := writer.Write(payload); err != nil {
		return nil, err
	}
	if err := writer.Close(); err != nil {
		return nil, err
	}
	return compressed.Bytes(), nil
}

func TestGzipPayload(t *testing.T) {
	got, err := gzipPayload([]byte("important payload"))
	if err != nil {
		t.Fatal(err)
	}
	// This golden byte sequence is not the API contract of gzip.Writer.
	want := []byte{0x1f, 0x8b, 0x08, 0x00}
	if !bytes.Equal(got, want) {
		t.Fatalf("gzip bytes = %x, want %x", got, want)
	}
}
```

### 2.4 Why this difference matters

Multiple valid gzip streams can decode to the same content. Exact-byte tests can fail after a harmless implementation change even though the documented compression behavior remains correct.

## 3. Boundaries and distinctions

Compare exact bytes when a format or API explicitly promises canonical, deterministic bytes, or when those bytes are themselves an external protocol contract. Otherwise, test decoded data and documented properties.
