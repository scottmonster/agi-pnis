# Account for negative zero when it is semantically relevant

## 1. Catalog record

- **Catalog identifier:** 4.1.12
- **Impact:** low
- **Consensus:** high
- **Definition:** JavaScript numbers include both `0` and `-0`. Use `Object.is(value, -0)` when distinguishing them genuinely matters instead of ordinary equality.

## 2. Example

### 2.1 Scenario

A charting system preserves the direction of a value that rounded to zero.

### 2.2 Preferred form

```javascript
function describeZero(value) {
  return Object.is(value, -0) ? "negative zero" : "zero";
}

console.log(describeZero(-0));
```

### 2.3 Hazardous form

```javascript
function describeZero(value) {
  return value === 0 ? "zero" : "nonzero";
}

console.log(describeZero(-0));
```

### 2.4 Why this difference matters

Ordinary equality considers `0` and `-0` equal, so the hazardous form loses a distinction that may encode direction or a domain state.

## 3. Boundaries and distinctions

Most application logic need not distinguish signed zero. Use `Object.is()` only when the sign of zero has defined meaning in the domain.
