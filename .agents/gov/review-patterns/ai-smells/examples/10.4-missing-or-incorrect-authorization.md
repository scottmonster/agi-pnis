# Missing or incorrect authorization

## 1. Catalog record

- **Catalog identifier:** 10.4
- **Evidence:** e
- **Definition:** Authenticates a caller but fails to enforce whether that caller may perform the requested action.

## 2. Scenario

### 2.1 Context

An authenticated support user can request a customer-data export.

### 2.2 Safer approach

After authentication, enforce the export permission and organization scope at the server before starting the job.

### 2.3 Failure mode

The agent checks that a session exists but starts an export for every signed-in user.

### 2.4 Why this difference matters

Authentication alone lets legitimate but insufficiently privileged accounts access restricted operations.

## 3. Boundaries and distinctions

This is distinct from missing authentication: identity is known here, but the action is not checked against that identity’s permissions.
