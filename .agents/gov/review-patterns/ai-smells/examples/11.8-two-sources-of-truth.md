# Two sources of truth

## 1. Catalog record

- **Catalog identifier:** 11.8
- **Evidence:** se
- **Definition:** Old and new configuration, mapping, or state representations coexist.

## 2. Scenario

### 2.1 Context

An application moves its role permissions from a Python dictionary to database-backed records.

### 2.2 Safer approach

The agent makes one representation authoritative, migrates the data, and has all permission checks read from that source.

### 2.3 Failure mode

The agent retains the dictionary for some checks while new administration screens write database records.

### 2.4 Why this difference matters

Permission changes can appear saved but have no effect in code paths that still consult the old mapping.

## 3. Boundaries and distinctions

Read-only compatibility copies may be necessary during a controlled transition, but they need clear authority, synchronization, and retirement rules.
