# Exact equality for computed floating-point values

## 1. Catalog record

- **Catalog identifier:** 6.21.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** When values are mathematically approximate, compare computed floats using a tolerance appropriate to the domain, commonly `math.isclose()`, rather than expecting exact decimal equality.

## 2. Example

### 2.1 Scenario

A billing check compares a computed total with an expected decimal amount.

### 2.2 Preferred form

```python
import math

total = 0.1 + 0.2
print(math.isclose(total, 0.3, rel_tol=1e-9))  # True
```

### 2.3 Hazardous form

```python
total = 0.1 + 0.2
print(total == 0.3)  # False
```

### 2.4 Why this difference matters

Most decimal fractions are approximated in binary floating point, so equivalent calculations can differ by a tiny rounding error.

## 3. Boundaries and distinctions

Choose tolerances from domain error limits. For exact decimal policy, such as currency storage, use `Decimal` or integral minor units instead.
