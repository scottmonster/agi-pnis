# `${array}` means element zero, not the whole array

## 1. Catalog record

- **Catalog identifier:** 7.3.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Referencing an indexed array without `[@]` or `[*]` behaves like a reference to subscript zero. Use `"${array[@]}"` when all elements are intended.

## 2. Example

### 2.1 Scenario

A release script must contact every configured mirror. Each mirror address can be passed as a separate argument to a command.

### 2.2 Preferred form

```bash
mirrors=(mirror-one mirror-two)

for mirror in "${mirrors[@]}"; do
  printf 'syncing %s\n' "$mirror"
done
```

### 2.3 Hazardous form

```bash
mirrors=(mirror-one mirror-two)

printf 'syncing %s\n' "${mirrors}"
```

### 2.4 Why this difference matters

The hazardous expansion prints only the value at index zero, so the second mirror is silently skipped. `[@]` makes the collection intent explicit and preserves each element as its own word when quoted.

## 3. Boundaries and distinctions

Using `${array}` is valid when the script deliberately needs element zero. Use `"${array[*]}"` only when a single joined word is specifically required.
