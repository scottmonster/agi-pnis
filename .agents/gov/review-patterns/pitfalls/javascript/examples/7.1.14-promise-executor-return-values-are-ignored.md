# Promise executor return values are ignored

## 1. Catalog record

- **Catalog identifier:** 7.1.14
- **Impact:** low
- **Consensus:** high
- **Definition:** Do not `return value` from a `new Promise()` executor expecting it to fulfill the promise. Use the provided `resolve` and `reject` functions.

## 2. Example

### 2.1 Scenario

A legacy adapter wraps a callback-style API in a promise.

### 2.2 Preferred form

```javascript
function getVersion() {
  return new Promise((resolve) => {
    resolve("1.2.0");
  });
}

getVersion().then(console.log, console.error);
```

### 2.3 Hazardous form

```javascript
function getVersion() {
  return new Promise(() => {
    return "1.2.0";
  });
}

getVersion().then(console.log, console.error);
```

### 2.4 Why this difference matters

The executor return value is ignored, leaving the hazardous promise pending forever instead of fulfilling with the version.

## 3. Boundaries and distinctions

Return values from Promise chain callbacks do affect the next chain promise; this rule applies specifically to the Promise constructor executor.
