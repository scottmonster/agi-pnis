# Range values are copies

## 1. Catalog record

- **Catalog identifier:** 7.11.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** When ranging over a slice or array, modifying the value variable does not modify the original element. Use the index when the element itself must change.

## 2. Example

### 2.1 Scenario

A batch job increments every integer in a slice.

### 2.2 Preferred form

```go
package batch

func increment(values []int) {
	for index := range values { values[index]++ }
}
```

### 2.3 Hazardous form

```go
package batch

func increment(values []int) {
	for _, value := range values { value++ }
}
```

### 2.4 Why this difference matters

Changing `value` changes only the range variable, leaving every original slice element unchanged.

## 3. Boundaries and distinctions

The value form is appropriate for read-only processing or when creating a deliberately independent derived value.
