# Constructing exact decimals from binary floats

## 1. Catalog record

- **Catalog identifier:** 7.2.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** When the intended value is a decimal literal such as money, construct `Decimal` from a string or other exact decimal representation rather than an already rounded binary float.

## 2. Example

### 2.1 Scenario

A price of ten cents is stored for currency arithmetic.

### 2.2 Preferred form

```python
from decimal import Decimal

price = Decimal("0.10")
print(price * 3)
```

### 2.3 Hazardous form

```python
from decimal import Decimal

price = Decimal(0.10)
print(price * 3)
```

### 2.4 Why this difference matters

The float has already approximated the decimal value, and `Decimal(0.10)` faithfully preserves that approximation.

## 3. Boundaries and distinctions

Constructing from a float is appropriate only when the binary float's exact value is intentionally the input being represented.
