# Use comma-ok when a closed channel's zero value is ambiguous

## 1. Catalog record

- **Catalog identifier:** 6.14.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `v, ok := <-ch` when the element type's zero value is meaningful and you need to distinguish it from closure.

## 2. Example

### 2.1 Scenario

A channel delivers a boolean decision where false is valid.

### 2.2 Preferred form

```go
package main

func decision(results <-chan bool) (bool, bool) {
	value, ok := <-results
	return value, ok
}
```

### 2.3 Hazardous form

```go
package main

func decision(results <-chan bool) bool { return <-results }
```

### 2.4 Why this difference matters

A closed `chan bool` returns false, exactly like a valid false decision. The `ok` value preserves the distinction.

## 3. Boundaries and distinctions

One-value receives can fit protocols where zero cannot be valid. Ranging also stops at closure.
