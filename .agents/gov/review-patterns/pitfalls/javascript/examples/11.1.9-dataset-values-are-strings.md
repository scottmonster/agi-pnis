# dataset values are strings

## 1. Catalog record

- **Catalog identifier:** 11.1.9
- **Impact:** medium
- **Consensus:** high
- **Definition:** Parse dataset values explicitly and remove a data attribute rather than assigning null.

## 2. Example

### 2.1 Scenario

A product card stores a quantity in a `data-quantity` attribute and clears an optional status flag.

### 2.2 Preferred form

```javascript
const card = document.querySelector(".product-card");
const quantity = Number(card.dataset.quantity);

if (Number.isInteger(quantity) && quantity > 0) {
  card.removeAttribute("data-status");
}
```

### 2.3 Hazardous form

```javascript
const card = document.querySelector(".product-card");

if (card.dataset.quantity + 1 === 3) {
  card.dataset.status = null;
}
```

### 2.4 Why this difference matters

Dataset access returns strings, so string concatenation changes the comparison, and assigning `null` stores the string `"null"` instead of removing the attribute.

## 3. Boundaries and distinctions

Dataset is suitable for simple string metadata. Validate and convert its values according to the domain before using them as numbers, booleans, or structured data.
