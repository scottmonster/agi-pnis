# A quoted tilde does not perform tilde expansion

## 1. Catalog record

- **Catalog identifier:** 10.9.1
- **Impact:** low
- **Consensus:** high
- **Definition:** `"~/file"` contains a literal tilde; use `"$HOME/file"` when a home-directory path must remain quoted.

## 2. Example

### 2.1 Scenario

A script needs a safe path to a configuration file in the current user's home directory.

### 2.2 Preferred form

```bash
config_path="$HOME/.config/example/settings.ini"
printf '%s\n' "$config_path"
```

### 2.3 Hazardous form

```bash
config_path="~/.config/example/settings.ini"
printf '%s\n' "$config_path"
```

### 2.4 Why this difference matters

Quoting protects spaces but also suppresses tilde expansion, leaving a literal `~` in the path and targeting the wrong location.

## 3. Boundaries and distinctions

An unquoted leading tilde may expand in an assignment word. Use `$HOME` when the full path also needs quoting or must be composed with other expansions.
