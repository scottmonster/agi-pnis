# Preserve descriptors explicitly when cloning accessor definitions

## 1. Catalog record

- **Catalog identifier:** 2.10.2
- **Impact:** low
- **Consensus:** high
- **Definition:** Copy property descriptors when definitions, rather than current values, must be preserved.

## 2. Example

### 2.1 Scenario

A model with a computed property is copied into a new object.

### 2.2 Preferred form

```javascript
const source = {
  firstName: "Ada",
  get displayName() {
    return this.firstName.toUpperCase();
  },
};

const copy = Object.defineProperties({}, Object.getOwnPropertyDescriptors(source));
```

### 2.3 Hazardous form

```javascript
const source = {
  firstName: "Ada",
  get displayName() {
    return this.firstName.toUpperCase();
  },
};

const copy = { ...source };
```

### 2.4 Why this difference matters

Object spread calls the getter and stores its current result as a data property, losing the accessor behavior in the copy.

## 3. Boundaries and distinctions

Spread is appropriate when copying current enumerable values is the intended result. Descriptor copying also retains non-enumerable and symbol properties.
