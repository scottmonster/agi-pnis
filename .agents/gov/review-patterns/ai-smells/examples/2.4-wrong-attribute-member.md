# Wrong attribute/member

## 1. Catalog record

- **Catalog identifier:** 2.4
- **Evidence:** e
- **Definition:** Uses a plausible but nonexistent property or method on a real object.

## 2. Scenario

### 2.1 Context

A handler receives a real `Request` object and must read its headers.

### 2.2 Safer approach

The agent reads the framework type or existing handlers and uses `request.headers.get("x-request-id")`.

### 2.3 Failure mode

It writes `request.header("x-request-id")`, assuming the object exposes a singular method.

### 2.4 Why this difference matters

The code fails at type-check time or runtime despite using a genuine object from the project.

## 3. Boundaries and distinctions

This is narrower than inventing an entire local symbol: the object exists, but the selected member does not.
