# Do not assume decodeURIComponent accepts arbitrary input

## 1. Catalog record

- **Catalog identifier:** 10.1.10
- **Impact:** medium
- **Consensus:** high
- **Definition:** Handle malformed encoding errors when decoding external input and do not treat plus as a decoded space.

## 2. Example

### 2.1 Scenario

A client decodes an opaque path segment supplied by an external redirect service.

### 2.2 Preferred form

```javascript
function decodePathSegment(value) {
  try {
    return decodeURIComponent(value);
  } catch {
    throw new RangeError("Path segment contains malformed percent encoding");
  }
}

console.log(decodePathSegment("report%2Barchive")); // report+archive
```

### 2.3 Hazardous form

```javascript
function decodePathSegment(value) {
  return decodeURIComponent(value).replaceAll("+", " ");
}

console.log(decodePathSegment("report%"));
```

### 2.4 Why this difference matters

Malformed percent encoding throws a `URIError`, and replacing plus signs corrupts valid path-segment data because `decodeURIComponent()` does not decode plus as a space.

## 3. Boundaries and distinctions

Form-encoded query parsing has different plus-sign rules and is better handled by `URLSearchParams`. Do not apply those rules to generic URI components.
