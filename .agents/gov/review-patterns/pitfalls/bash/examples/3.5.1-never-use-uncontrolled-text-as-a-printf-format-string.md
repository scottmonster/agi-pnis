# Never use uncontrolled text as a printf format string

## 1. Catalog record

- **Catalog identifier:** 3.5.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Print supplied text with a fixed `printf` format such as `'%s\\n'`, not as the format string itself.

## 2. Example

### 2.1 Scenario

A command-line utility prints a message provided by a user or another program.

### 2.2 Preferred form

```bash
message='progress: 100% complete'
printf '%s\n' "$message"
```

### 2.3 Hazardous form

```bash
message='progress: 100% complete'
printf "$message"
```

### 2.4 Why this difference matters

`printf` treats its first argument as formatting instructions, so percent sequences in data can be interpreted instead of printed literally.

## 3. Boundaries and distinctions

Construct a dynamic format string only when its directives are authored and validated by the script, not supplied as ordinary data.
