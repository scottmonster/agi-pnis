# Assuming a shallow copy duplicates nested state

## 1. Catalog record

- **Catalog identifier:** 6.2.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use a shallow copy only when sharing nested objects is acceptable. Consider deliberate reconstruction or `deepcopy()` when nested independence is required.

## 2. Example

### 2.1 Scenario

A template contains nested mutable settings that each job must be able to edit independently.

### 2.2 Preferred form

```python
from copy import deepcopy


template = {"retry": {"delays": [1, 2]}}
job_settings = deepcopy(template)
job_settings["retry"]["delays"].append(5)

assert template["retry"]["delays"] == [1, 2]
```

### 2.3 Hazardous form

```python
template = {"retry": {"delays": [1, 2]}}
job_settings = template.copy()
job_settings["retry"]["delays"].append(5)

assert template["retry"]["delays"] == [1, 2, 5]
```

### 2.4 Why this difference matters

A shallow copy replaces only the outer dictionary. The inner dictionary and list remain shared, so nested mutation leaks back to the template.

## 3. Boundaries and distinctions

`deepcopy()` can be inappropriate for objects with external resources or deliberate sharing. Explicit reconstruction is often clearer for complex models.
