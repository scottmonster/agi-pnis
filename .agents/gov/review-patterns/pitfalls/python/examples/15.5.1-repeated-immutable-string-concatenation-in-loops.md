# Repeated immutable-string concatenation in loops

## 1. Catalog record

- **Catalog identifier:** 15.5.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Prefer `str.join()` or an appropriate buffer when constructing a string from many pieces instead of repeatedly growing an immutable string.

## 2. Example

### 2.1 Scenario

A report generator combines thousands of formatted rows into one response body.

### 2.2 Preferred form

```python
def render_report(rows: list[str]) -> str:
    return "\n".join(rows)
```

### 2.3 Hazardous form

```python
def render_report(rows: list[str]) -> str:
    report = ""
    for row in rows:
        report += row + "\n"
    return report
```

### 2.4 Why this difference matters

Strings are immutable, so repeated growth can repeatedly copy the accumulated content. For large inputs, that work can become quadratic.

## 3. Boundaries and distinctions

Small, infrequent concatenations are usually clear and inexpensive. Prefer `join()` or a buffer when assembling many fragments or when profiling identifies this path as hot.
