# Never pass a nil context

## 1. Catalog record

- **Catalog identifier:** 9.2.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Pass `context.TODO()` when no proper context has yet been chosen rather than passing nil.

## 2. Example

### 2.1 Scenario

A command-line migration has not yet established a request or shutdown context.

### 2.2 Preferred form

```go
package example

import "context"

func migrate(ctx context.Context) error { return ctx.Err() }

func run() error {
	return migrate(context.TODO())
}
```

### 2.3 Hazardous form

```go
package example

import "context"

func migrate(ctx context.Context) error { return ctx.Err() }

func run() error {
	return migrate(nil) // Context methods may panic.
}
```

### 2.4 Why this difference matters

`context.TODO` is a valid non-nil context and clearly marks unfinished context selection. Nil moves a runtime failure into the called function.

## 3. Boundaries and distinctions

Prefer `context.Background` for a deliberate root context and replace `TODO` with a caller-provided context when the operation gains cancellation or deadline requirements.
