# Wrong method/function input

## 1. Catalog record

- **Catalog identifier:** 6.3
- **Evidence:** e
- **Definition:** Incorrect parameter value, type, order, unit, or semantic meaning.

## 2. Scenario

### 2.1 Context

The payment SDK expects an amount in cents and a currency code.

### 2.2 Safer approach

The agent checks the local SDK wrapper and passes `amount_cents=1999, currency="USD"`.

### 2.3 Failure mode

It passes `19.99` as the amount, treating dollars as cents.

### 2.4 Why this difference matters

The charge can be one hundredth of the intended amount despite calling the correct API.

## 3. Boundaries and distinctions

This is about an input's value or meaning; selecting an unavailable API is a public API hallucination or API misuse.
