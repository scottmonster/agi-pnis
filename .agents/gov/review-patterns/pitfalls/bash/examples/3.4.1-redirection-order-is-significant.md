# Redirection order is significant

## 1. Catalog record

- **Catalog identifier:** 3.4.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Apply stdout redirection before duplicating stderr when both streams must go to the same destination.

## 2. Example

### 2.1 Scenario

A batch job must save both its normal output and diagnostics in one log file.

### 2.2 Preferred form

```bash
run_job() {
  printf 'started\n'
  printf 'warning: cache is cold\n' >&2
}

run_job > job.log 2>&1
```

### 2.3 Hazardous form

```bash
run_job() {
  printf 'started\n'
  printf 'warning: cache is cold\n' >&2
}

run_job 2>&1 > job.log
```

### 2.4 Why this difference matters

Redirections are processed left to right. The hazardous order sends stderr to the original stdout, leaving diagnostics outside `job.log`.

## 3. Boundaries and distinctions

Use the reversed order only when intentionally separating stderr from redirected stdout.
