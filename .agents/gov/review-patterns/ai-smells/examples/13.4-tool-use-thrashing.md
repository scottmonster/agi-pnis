# Tool-use thrashing

## 1. Catalog record

- **Catalog identifier:** 13.4
- **Evidence:** a
- **Definition:** Repeats searches, builds, installs, or shell commands without gaining new information.

## 2. Scenario

### 2.1 Context

A test fails because a required environment variable is absent in the test command.

### 2.2 Safer approach

The agent reads the error, inspects the test setup, supplies the documented fixture or variable, and reruns the affected test.

### 2.3 Failure mode

The agent reruns the same failing command, repeatedly reinstalls dependencies, and repeats the identical search without changing its hypothesis.

### 2.4 Why this difference matters

Repeated commands consume time while leaving the cause and next action unchanged.

## 3. Boundaries and distinctions

A rerun is useful after a relevant change or to rule out transient failure. Thrashing is repetition without a new input, observation, or decision.
