# Remember that optional chaining only guards its chain

## 1. Catalog record

- **Catalog identifier:** 6.4.2
- **Impact:** medium
- **Consensus:** high
- **Definition:** Do not assume `foo?.bar` protects later independent operations such as arithmetic on the resulting value.

## 2. Example

### 2.1 Scenario

A profile may be absent before its display name is formatted.

### 2.2 Preferred form

```typescript
type Profile = { displayName: string };

function label(profile: Profile | undefined): string {
  return profile?.displayName.toUpperCase() ?? 'Anonymous';
}

```

### 2.3 Hazardous form

```typescript
type Profile = { displayName: string };

function label(profile: Profile | undefined): string {
  return (profile?.displayName).toUpperCase(); // The parentheses end the guarded chain.
}
```

### 2.4 Why this difference matters

The expression can still evaluate to `undefined`, which later code must account for.

## 3. Boundaries and distinctions

Apply this guidance in the conditions described by the catalog record. Deliberate exceptions need a documented runtime guarantee, compatible toolchain behavior, or an explicit local unsafe boundary.
