# Search/exploration underreach

## 1. Catalog record

- **Catalog identifier:** 13.2
- **Evidence:** a
- **Definition:** Fails to inspect the files or definitions that contain the decisive information.

## 2. Scenario

### 2.1 Context

A task asks to add an optional timeout to an API client. A shared configuration schema defines how client options are loaded.

### 2.2 Safer approach

The agent traces construction of the client, reads the schema and its validation tests, and adds the option through the established configuration path.

### 2.3 Failure mode

The agent edits only the client constructor and adds a parameter that no configuration loader or caller can supply.

### 2.4 Why this difference matters

The new capability looks implemented locally but is inaccessible in deployed configurations.

## 3. Boundaries and distinctions

Exploration should target decisions that affect the change. This is underreach, not a requirement to read every file in the repository.
