# Irrelevant command execution

## 1. Catalog record

- **Catalog identifier:** 13.5
- **Evidence:** a
- **Definition:** Runs installs or shell operations when the task calls for a simple code/document edit.

## 2. Scenario

### 2.1 Context

A user requests a correction to a command shown in a README.

### 2.2 Safer approach

The agent confirms the intended command against the adjacent documentation, edits the Markdown, and reviews the diff.

### 2.3 Failure mode

The agent installs project dependencies, starts services, and runs a full build before changing the documented command.

### 2.4 Why this difference matters

Unneeded commands add delay and may mutate the working tree or local environment without validating the requested documentation edit.

## 3. Boundaries and distinctions

Commands are appropriate when they verify a behavior affected by the task. This failure is about commands unrelated to the requested outcome.
