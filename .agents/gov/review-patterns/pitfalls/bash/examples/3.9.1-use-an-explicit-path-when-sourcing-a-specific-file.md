# Use an explicit path when sourcing a specific file

## 1. Catalog record

- **Catalog identifier:** 3.9.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Source a specific file with an explicit or deliberately resolved path instead of relying on `PATH` lookup.

## 2. Example

### 2.1 Scenario

A release script needs settings from the `release.env` file beside the script.

### 2.2 Preferred form

```bash
script_dir=$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)
source "$script_dir/release.env"
```

### 2.3 Hazardous form

```bash
PATH='/tmp/tools:/usr/local/bin:/usr/bin'
source release.env
```

### 2.4 Why this difference matters

Without an explicit path, Bash can select another file named `release.env` through environment-dependent lookup behavior.

## 3. Boundaries and distinctions

Bare `source name` is acceptable only when searching `PATH` is intentional and the search path is controlled.
