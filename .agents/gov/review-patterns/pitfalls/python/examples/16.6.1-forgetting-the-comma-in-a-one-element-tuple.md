# Forgetting the comma in a one-element tuple

## 1. Catalog record

- **Catalog identifier:** 16.6.1
- **Impact:** low
- **Consensus:** high
- **Definition:** Write `(value,)` for a one-element tuple. Parentheses alone do not make a tuple.

## 2. Example

### 2.1 Scenario

A query builder accepts a tuple of database parameters, even when only one parameter is supplied.

### 2.2 Preferred form

```python
def parameter_tuple(user_id: int) -> tuple[int]:
    return (user_id,)
```

### 2.3 Hazardous form

```python
def parameter_tuple(user_id: int) -> int:
    return (user_id)
```

### 2.4 Why this difference matters

The parentheses only group the expression. Without the comma, callers receive an integer rather than the one-element tuple expected by the parameter API.

## 3. Boundaries and distinctions

Parentheses remain useful for grouping expressions and for tuples with multiple comma-separated items. The comma is what gives a single-item expression tuple semantics.
