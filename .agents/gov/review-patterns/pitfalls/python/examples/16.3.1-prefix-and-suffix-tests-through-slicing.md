# Prefix and suffix tests through slicing

## 1. Catalog record

- **Catalog identifier:** 16.3.1
- **Impact:** low
- **Consensus:** high
- **Definition:** Prefer `startswith()` and `endswith()` over manual slices when testing a prefix or suffix.

## 2. Example

### 2.1 Scenario

A router accepts only request paths that end in the `.json` extension.

### 2.2 Preferred form

```python
def accepts_json(path: str) -> bool:
    return path.endswith(".json")
```

### 2.3 Hazardous form

```python
def accepts_json(path: str) -> bool:
    return path[-5:] == ".json"
```

### 2.4 Why this difference matters

The dedicated method communicates the operation and avoids maintaining a separate literal length. It also makes the code easier to adapt to multiple accepted suffixes.

## 3. Boundaries and distinctions

Slicing is appropriate when the sliced value is needed for further processing. Use `startswith()` or `endswith()` when the intent is specifically a prefix or suffix test.
