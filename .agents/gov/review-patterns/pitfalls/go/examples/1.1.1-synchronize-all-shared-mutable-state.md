# Synchronize all shared mutable state

## 1. Catalog record

- **Catalog identifier:** 1.1.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Do not read and write shared memory concurrently without synchronization. Use channels, mutexes, atomics, or another documented happens-before relationship.

## 2. Example

### 2.1 Scenario

Several workers add processed byte counts to one request-level total.

### 2.2 Preferred form

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var mu sync.Mutex
	total := 0
	var wg sync.WaitGroup
	for _, bytes := range []int{120, 80} {
		wg.Go(func() {
			mu.Lock()
			total += bytes
			mu.Unlock()
		})
	}
	wg.Wait()
	fmt.Println(total)
}
```

### 2.3 Hazardous form

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	total := 0
	var wg sync.WaitGroup
	for _, bytes := range []int{120, 80} {
		wg.Go(func() { total += bytes })
	}
	wg.Wait()
	fmt.Println(total)
}
```

### 2.4 Why this difference matters

The hazardous updates race and can lose increments. A mutex establishes exclusive access and makes the accumulated result reliable.

## 3. Boundaries and distinctions

An atomic counter can also fit a simple numeric operation. Synchronization is still required even when a later wait ensures workers have stopped.
