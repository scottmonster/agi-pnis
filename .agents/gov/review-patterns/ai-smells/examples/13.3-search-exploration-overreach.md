# Search/exploration overreach

## 1. Catalog record

- **Catalog identifier:** 13.3
- **Evidence:** a
- **Definition:** Burns large amounts of time/tokens browsing irrelevant portions of the repository.

## 2. Scenario

### 2.1 Context

A requested documentation typo fix identifies the exact Markdown file and line.

### 2.2 Safer approach

The agent reads the surrounding section, corrects the typo, and verifies the diff.

### 2.3 Failure mode

The agent recursively searches vendored dependencies, old release notes, and generated documentation before making the one-word edit.

### 2.4 Why this difference matters

Irrelevant investigation delays delivery and can create noise without increasing confidence in the edit.

## 3. Boundaries and distinctions

Broad exploration is appropriate when scope or ownership is genuinely unclear. It is overreach when the findings cannot affect the decision at hand.
