# Quote here-document delimiters for literal bodies

## 1. Catalog record

- **Catalog identifier:** 3.1.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Quote a here-document delimiter when its body must remain literal and must not perform shell expansions.

## 2. Example

### 2.1 Scenario

A deployment script writes a configuration template containing syntax that must be preserved for a later process.

### 2.2 Preferred form

```bash
cat > app.conf <<'EOF'
database_url=${DATABASE_URL}
worker_count=$((CPU_COUNT * 2))
EOF
```

### 2.3 Hazardous form

```bash
DATABASE_URL='postgres://production'
CPU_COUNT=4

cat > app.conf <<EOF
database_url=${DATABASE_URL}
worker_count=$((CPU_COUNT * 2))
EOF
```

### 2.4 Why this difference matters

The unquoted delimiter expands parameters and arithmetic before writing the file, so a template can be changed or execute command substitutions unexpectedly.

## 3. Boundaries and distinctions

Leave the delimiter unquoted only when expansion of the body is intentional and all expanded values are controlled.
