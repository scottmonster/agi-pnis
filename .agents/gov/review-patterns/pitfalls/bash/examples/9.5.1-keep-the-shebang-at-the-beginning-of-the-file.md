# Keep the shebang at the beginning of the file

## 1. Catalog record

- **Catalog identifier:** 9.5.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Place the `#!` interpreter line at the first position in an executable shell script.

## 2. Example

### 2.1 Scenario

An executable maintenance script relies on Bash features and is invoked directly by an automation service.

### 2.2 Preferred form

```bash
#!/usr/bin/env bash
# Rotate the application log.
set -euo pipefail

printf 'rotating logs\n'
```

### 2.3 Hazardous form

```bash
# Rotate the application log.
#!/usr/bin/env bash
set -euo pipefail

printf 'rotating logs\n'
```

### 2.4 Why this difference matters

The kernel recognizes an interpreter directive only at the beginning of the file, so direct execution can use the wrong interpreter or fail.

## 3. Boundaries and distinctions

The shebang does not control execution when an explicit interpreter, such as `bash script.sh`, is supplied by the caller.
