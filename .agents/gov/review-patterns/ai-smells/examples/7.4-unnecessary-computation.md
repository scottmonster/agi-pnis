# Unnecessary computation

## 1. Catalog record

- **Catalog identifier:** 7.4
- **Evidence:** e
- **Definition:** Performs work irrelevant to the output.

## 2. Scenario

### 2.1 Context

An agent adds an endpoint that returns a user's display name.

### 2.2 Safer approach

It retrieves only the user record and constructs the requested response.

### 2.3 Failure mode

It also calculates that user's complete activity summary, although none of it is returned or used.

### 2.4 Why this difference matters

The endpoint consumes resources and adds failure paths for work that cannot affect its output.

## 3. Boundaries and distinctions

Preparatory work is not unnecessary when it supports validation, authorization, or a required side effect; the distinction is whether it is relevant to the result or required behavior.
