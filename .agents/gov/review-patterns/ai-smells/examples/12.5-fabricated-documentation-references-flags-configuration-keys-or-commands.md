# Fabricated documentation references, flags, configuration keys, or commands

## 1. Catalog record

- **Catalog identifier:** 12.5
- **Evidence:** se
- **Definition:** Documents plausible but nonexistent resources that send users toward failed setup or operation.

## 2. Scenario

### 2.1 Context

Troubleshooting instructions tell operators to run `appctl cache --repair`, although the CLI has no `cache` subcommand or repair flag.

### 2.2 Safer approach

Confirm documented commands, flags, keys, and links against the shipped CLI, schema, or repository before publishing the instructions.

### 2.3 Failure mode

Add the plausible-sounding repair command based on an assumption without checking whether it exists.

### 2.4 Why this difference matters

Operators lose time following a dead end during an incident and may infer unsupported recovery behavior.

## 3. Boundaries and distinctions

This concerns a resource that does not exist. It differs from stale documentation for a real resource whose contract changed.
