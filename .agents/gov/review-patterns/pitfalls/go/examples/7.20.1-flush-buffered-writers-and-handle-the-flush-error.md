# Flush buffered writers and handle the flush error

## 1. Catalog record

- **Catalog identifier:** 7.20.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Explicitly flush `bufio.Writer` and similar buffered encoders before the underlying destination is considered successfully written.

## 2. Example

### 2.1 Scenario

A service writes a generated response into an arbitrary `io.Writer`.

### 2.2 Preferred form

```go
package export

import (
	"bufio"
	"io"
)

func writeReport(destination io.Writer) error {
	writer := bufio.NewWriter(destination)
	if _, err := writer.WriteString("complete\\n"); err != nil { return err }
	return writer.Flush()
}
```

### 2.3 Hazardous form

```go
package export

import (
	"bufio"
	"io"
)

func writeReport(destination io.Writer) error {
	writer := bufio.NewWriter(destination)
	_, err := writer.WriteString("complete\\n")
	return err // Buffered bytes and delayed errors are ignored.
}
```

### 2.4 Why this difference matters

The final write to the destination can fail during `Flush`, after `WriteString` has appeared to succeed.

## 3. Boundaries and distinctions

An unbuffered destination has no separate flush operation. Still check errors from every actual write.
