# `${array}` means element zero, not the whole array

## 1. Catalog record

- **Catalog identifier:** 6.11.2
- **Impact:** medium
- **Consensus:** high
- **Definition:** Referencing an indexed array without `[@]` or `[*]` behaves like a reference to subscript zero. Use `"${array[@]}"` when all elements are intended.

## 2. Example

### 2.1 Scenario

A build script passes all selected test suites to its runner.

### 2.2 Preferred form

```bash
#!/usr/bin/env bash
suites=(unit integration smoke)
for suite in "${suites[@]}"; do echo "running $suite"; done
```

### 2.3 Hazardous form

```bash
#!/usr/bin/env bash
suites=(unit integration smoke)
for suite in "${suites}"; do echo "running $suite"; done
```

### 2.4 Why this difference matters

The hazardous expansion produces only `unit`, silently omitting all remaining suites.

## 3. Boundaries and distinctions

An unadorned indexed-array expansion is valid when element zero is explicitly intended. Use `"${array[*]}"` when one joined string is intended.
