# const does not make objects immutable

## 1. Catalog record

- **Catalog identifier:** 1.1.11
- **Impact:** medium
- **Consensus:** high
- **Definition:** `const` prevents reassignment of the binding but does not freeze the referenced array or object. Use immutability techniques separately when mutation must be prevented.

## 2. Example

### 2.1 Scenario

A function prepares updated preferences without changing the caller's current preferences.

### 2.2 Preferred form

```javascript
function enableAlerts(preferences) {
  return { ...preferences, alerts: true };
}

const currentPreferences = { alerts: false };
console.log(enableAlerts(currentPreferences));
console.log(currentPreferences);
```

### 2.3 Hazardous form

```javascript
const preferences = { alerts: false };
preferences.alerts = true;

console.log(preferences);
```

### 2.4 Why this difference matters

`const` protects the variable binding only. The hazardous form mutates the shared object and can surprise other code holding the same reference.

## 3. Boundaries and distinctions

`Object.freeze()` can prevent immediate property writes, but it is shallow. Deep immutability needs a deliberate design.
