# Generic helper with one caller

## 1. Catalog record

- **Catalog identifier:** 3.4
- **Evidence:** se
- **Definition:** Extracts a parameterized mini-framework from code that has one concrete use.

## 2. Scenario

### 2.1 Context

One import job normalizes a partner CSV before saving it.

### 2.2 Safer approach

Keep the normalization near that import job with names tied to the partner format.

### 2.3 Failure mode

Extract a generic pipeline helper with type parameters, hooks, and options for the sole importer.

### 2.4 Why this difference matters

The abstraction hides the business operation while adding an interface no second use has validated.

## 3. Boundaries and distinctions

Extraction can be warranted after stable duplication appears; one caller alone does not establish a reusable boundary.
