# Optional chaining only short-circuits a continuous chain

## 1. Catalog record

- **Catalog identifier:** 1.1.21
- **Impact:** medium
- **Consensus:** high
- **Definition:** Keep optional access within the intended chain. Grouping an intermediate expression, such as `(obj?.a).b`, ends the short-circuit protection before `.b`.

## 2. Example

### 2.1 Scenario

A profile may not have an address, and the UI needs its city when available.

### 2.2 Preferred form

```javascript
function cityFor(profile) {
  return profile?.address?.city;
}

console.log(cityFor({ name: "Ari" }));
```

### 2.3 Hazardous form

```javascript
function cityFor(profile) {
  return (profile?.address).city;
}

console.log(cityFor({ name: "Ari" }));
```

### 2.4 Why this difference matters

The parentheses end the optional chain. When `address` is absent, the later `.city` access runs on `undefined` and throws.

## 3. Boundaries and distinctions

Grouping is safe when the grouped expression is guaranteed non-nullish. Keep the chain continuous for every access that needs protection.
