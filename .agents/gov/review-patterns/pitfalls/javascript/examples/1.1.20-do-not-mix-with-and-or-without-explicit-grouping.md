# Do not mix ?? with && or || without explicit grouping

## 1. Catalog record

- **Catalog identifier:** 1.1.20
- **Impact:** medium
- **Consensus:** high
- **Definition:** Add parentheses when combining nullish coalescing with logical AND or OR. JavaScript intentionally rejects unparenthesized mixing of these operators.

## 2. Example

### 2.1 Scenario

A display label uses an explicit label when present, otherwise a feature-specific fallback, then a general fallback.

### 2.2 Preferred form

```javascript
function displayLabel(label, featureEnabled) {
  return label ?? (featureEnabled || "Untitled");
}

console.log(displayLabel(null, false));
```

### 2.3 Hazardous form

```javascript
const source = 'const label = preferred ?? featureEnabled || "Untitled";';

try {
  new Function(source);
} catch (error) {
  console.log(error.name);
}
```

### 2.4 Why this difference matters

The unparenthesized expression is rejected with a syntax error, preventing the application from loading until the intended grouping is made explicit.

## 3. Boundaries and distinctions

This restriction applies to mixing `??` with `&&` or `||`. Parentheses both satisfy the grammar and document the required evaluation order.
