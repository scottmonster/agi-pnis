# Object.freeze is shallow

## 1. Catalog record

- **Catalog identifier:** 2.13.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Do not treat `Object.freeze()` as recursively immutable.

## 2. Example

### 2.1 Scenario

An application exposes settings that contain nested retry configuration.

### 2.2 Preferred form

```javascript
const settings = {
  retry: Object.freeze({ attempts: 3 }),
};
Object.freeze(settings);

console.log(Object.isFrozen(settings.retry));
```

### 2.3 Hazardous form

```javascript
const settings = Object.freeze({
  retry: { attempts: 3 },
});

settings.retry.attempts = 5;
console.log(settings.retry.attempts);
```

### 2.4 Why this difference matters

Freezing the outer object does not freeze its nested `retry` object, so the nested value remains mutable.

## 3. Boundaries and distinctions

Freeze individual nested objects, use a deliberate deep-freeze utility, or use immutable data structures when recursive immutability is required.
