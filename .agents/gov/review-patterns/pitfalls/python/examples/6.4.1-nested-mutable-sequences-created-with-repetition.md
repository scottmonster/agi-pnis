# Nested mutable sequences created with repetition

## 1. Catalog record

- **Catalog identifier:** 6.4.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Do not create independent nested mutable containers with expressions such as `[[None] * width] * height`. Use a comprehension that constructs each inner object separately.

## 2. Example

### 2.1 Scenario

A grid needs independent rows so one cell edit does not affect every row.

### 2.2 Preferred form

```python
width = 3
height = 2
grid = [[None] * width for _ in range(height)]
grid[0][1] = "X"

assert grid == [[None, "X", None], [None, None, None]]
```

### 2.3 Hazardous form

```python
width = 3
height = 2
grid = [[None] * width] * height
grid[0][1] = "X"

assert grid == [[None, "X", None], [None, "X", None]]
```

### 2.4 Why this difference matters

Sequence repetition repeats references to the same inner list. The hazardous grid has two names for one row object.

## 3. Boundaries and distinctions

Repetition is safe for immutable inner values. It is the repeated mutable inner container that creates aliasing.
