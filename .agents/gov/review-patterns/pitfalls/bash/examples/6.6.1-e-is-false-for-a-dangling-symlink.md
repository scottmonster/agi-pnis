# `-e` is false for a dangling symlink

## 1. Catalog record

- **Catalog identifier:** 6.6.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** `[[ -e path ]]` follows the symlink target, so a broken symbolic link does not satisfy it. Use `-L` or `-h` when the existence of the link object itself is what matters.

## 2. Example

### 2.1 Scenario

A cleanup operation removes a symbolic-link alias even if the target is gone.

### 2.2 Preferred form

```bash
#!/usr/bin/env bash
alias_path=$1
if [[ -L $alias_path ]]; then rm -- "$alias_path"; fi
```

### 2.3 Hazardous form

```bash
#!/usr/bin/env bash
alias_path=$1
if [[ -e $alias_path ]]; then rm -- "$alias_path"; fi
```

### 2.4 Why this difference matters

`-e` follows the target and returns false for a dangling link, leaving the link object behind.

## 3. Boundaries and distinctions

Use `-e` when target availability matters. Use `-L` or `-h` when managing the link object itself.
