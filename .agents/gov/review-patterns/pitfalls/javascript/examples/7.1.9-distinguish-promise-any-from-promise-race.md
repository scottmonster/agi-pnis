# Distinguish Promise.any from Promise.race

## 1. Catalog record

- **Catalog identifier:** 7.1.9
- **Impact:** medium
- **Consensus:** high
- **Definition:** `Promise.race()` adopts the first settlement, whether fulfillment or rejection. `Promise.any()` waits for the first fulfillment and only rejects if all inputs reject.

## 2. Example

### 2.1 Scenario

An image loader should use the first mirror that successfully returns an image, despite a faster mirror failing.

### 2.2 Preferred form

```javascript
const failedMirror = Promise.reject(new Error("mirror A unavailable"));
const workingMirror = Promise.resolve("image bytes");

Promise.any([failedMirror, workingMirror])
  .then(console.log)
  .catch(console.error);
```

### 2.3 Hazardous form

```javascript
const failedMirror = Promise.reject(new Error("mirror A unavailable"));
const workingMirror = Promise.resolve("image bytes");

Promise.race([failedMirror, workingMirror])
  .then(console.log)
  .catch(console.error);
```

### 2.4 Why this difference matters

Promise.race can reject because the first settlement is a failure, even though another source can still fulfill the request.

## 3. Boundaries and distinctions

Use Promise.race when the first settlement itself is the desired policy, such as racing a result against a timeout.
