# Do not assume `bufio.Scanner` handles arbitrarily large tokens

## 1. Catalog record

- **Catalog identifier:** 7.19.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Check `Scanner.Err`, and configure `Scanner.Buffer` or use a `bufio.Reader` when tokens can exceed Scanner's configured maximum.

## 2. Example

### 2.1 Scenario

An import endpoint accepts line-oriented records that can contain large JSON payloads.

### 2.2 Preferred form

```go
package importfile

import (
	"bufio"
	"io"
)

func lines(input io.Reader) error {
	scanner := bufio.NewScanner(input)
	scanner.Buffer(make([]byte, 1024), 2*1024*1024)
	for scanner.Scan() { _ = scanner.Text() }
	return scanner.Err()
}
```

### 2.3 Hazardous form

```go
package importfile

import (
	"bufio"
	"io"
)

func lines(input io.Reader) {
	scanner := bufio.NewScanner(input)
	for scanner.Scan() { _ = scanner.Text() }
	// A token over Scanner's limit stops the loop, and this ignores scanner.Err().
}
```

### 2.4 Why this difference matters

Without checking the error, an oversized token can look like ordinary end of input and silently drop remaining records.

## 3. Boundaries and distinctions

The default limit is suitable only when the format imposes a known safe maximum. Use `bufio.Reader` for formats with unbounded records.
