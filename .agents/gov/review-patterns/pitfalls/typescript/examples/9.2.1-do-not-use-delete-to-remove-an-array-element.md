# Do not use `delete` to remove an array element

## 1. Catalog record

- **Catalog identifier:** 9.2.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `splice`, filtering, or another explicit array operation rather than `delete array[index]`.

## 2. Example

### 2.1 Scenario

A queue removes its failed job while keeping a dense sequence for later processing.

### 2.2 Preferred form

```typescript
const queue = ['send-email', 'resize-image', 'publish-report'];
queue.splice(1, 1);

console.log(queue); // ['send-email', 'publish-report']
```

### 2.3 Hazardous form

```typescript
const queue = ['send-email', 'resize-image', 'publish-report'];
delete queue[1];

console.log(queue.length); // 3
console.log(queue.map((job) => job)); // the hole is skipped
```

### 2.4 Why this difference matters

`delete` creates a sparse hole while leaving the array's length unchanged, which rarely matches the intended array semantics.

## 3. Boundaries and distinctions

Apply this guidance in the conditions described by the catalog record. Deliberate exceptions need a documented runtime guarantee, compatible toolchain behavior, or an explicit local unsafe boundary.
