# Mediator for a tiny object graph

## 1. Catalog record

- **Catalog identifier:** 3.18
- **Evidence:** se
- **Definition:** Adds a mediation layer where dependencies are already simple and explicit.

## 2. Scenario

### 2.1 Context

A form calls a validator and then a presenter.

### 2.2 Safer approach

Wire the validator and presenter directly in the form flow.

### 2.3 Failure mode

Introduce a mediator that relays the two calls without managing complex interaction.

### 2.4 Why this difference matters

The relay obscures simple dependencies and adds a new place for routing defects.

## 3. Boundaries and distinctions

Mediators can clarify a genuinely dense object graph; this failure applies when relationships are already few and explicit.
