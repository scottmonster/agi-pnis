# Treat archive entry paths and links as hostile

## 1. Catalog record

- **Catalog identifier:** 4.5.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Do not assume a tar or zip reader makes extracted paths safe. Ensure every extraction remains inside its output root, ideally using `os.Root`.

## 2. Example

### 2.1 Scenario

A service extracts uploaded tar archives into a dedicated working directory.

### 2.2 Preferred form

```go
package example

import (
	"archive/tar"
	"fmt"
	"io"
	"os"
)

func extractRegularFiles(r *tar.Reader, destination string) error {
	root, err := os.OpenRoot(destination)
	if err != nil {
		return err
	}
	defer root.Close()
	for {
		h, err := r.Next()
		if err == io.EOF {
			return nil
		}
		if err != nil {
			return err
		}
		if h.Typeflag != tar.TypeReg {
			return fmt.Errorf("unsupported archive entry %q", h.Name)
		}
		f, err := root.OpenFile(h.Name, os.O_WRONLY|os.O_CREATE|os.O_EXCL, 0o600)
		if err != nil {
			return err
		}
		_, copyErr := io.Copy(f, r)
		closeErr := f.Close()
		if copyErr != nil {
			return copyErr
		}
		if closeErr != nil {
			return closeErr
		}
	}
}
```

### 2.3 Hazardous form

```go
package example

import (
	"archive/tar"
	"io"
	"os"
	"path/filepath"
)

func extractFiles(r *tar.Reader, destination string) error {
	for {
		h, err := r.Next()
		if err == io.EOF {
			return nil
		}
		if err != nil {
			return err
		}
		path := filepath.Join(destination, h.Name)
		f, err := os.Create(path)
		if err != nil {
			return err
		}
		if _, err := io.Copy(f, r); err != nil {
			f.Close()
			return err
		}
		if err := f.Close(); err != nil {
			return err
		}
	}
}
```

### 2.4 Why this difference matters

Archive names can contain traversal segments, absolute paths, or entries that exploit links. The root-relative form rejects escapes and rejects link entries, while direct joining can overwrite files outside the extraction directory.

## 3. Boundaries and distinctions

An extractor may support directories or links only after applying a deliberate containment policy to each kind. Archive size limits, entry counts, and file permissions need separate controls.
