# Incomplete privilege dropping with `subprocess`

## 1. Catalog record

- **Catalog identifier:** 2.7.1
- **Impact:** high
- **Consensus:** high
- **Definition:** On POSIX, do not assume `Popen(user=...)` alone removes supplementary groups. When dropping privileges requires it, explicitly set `extra_groups=()`.

## 2. Example

### 2.1 Scenario

A POSIX worker launches an untrusted document converter with a restricted account.

### 2.2 Preferred form

```python
import subprocess


def convert_document(path: str) -> subprocess.CompletedProcess[str]:
    return subprocess.run(
        ["converter", "--input", path],
        user="converter",
        group="converter",
        extra_groups=(),
        check=True,
        text=True,
    )


convert_document("report.docx")
```

### 2.3 Hazardous form

```python
import subprocess


def convert_document(path: str) -> subprocess.CompletedProcess[str]:
    return subprocess.run(
        ["converter", "--input", path],
        user="converter",
        check=True,
        text=True,
    )


convert_document("report.docx")
```

### 2.4 Why this difference matters

Changing only the user can leave inherited supplementary group permissions available to the child process.

## 3. Boundaries and distinctions

This POSIX-specific concern matters when the privilege boundary requires dropping supplementary groups. Verify the complete operating-system credential policy for the service.
