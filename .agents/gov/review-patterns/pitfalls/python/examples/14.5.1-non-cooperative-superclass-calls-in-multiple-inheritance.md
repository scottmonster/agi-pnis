# Non-cooperative superclass calls in multiple inheritance

## 1. Catalog record

- **Catalog identifier:** 14.5.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** In classes designed for cooperative multiple inheritance, use compatible method signatures and `super()` throughout the cooperating hierarchy rather than hard-coding a particular parent call.

## 2. Example

### 2.1 Scenario

A storage class combines JSON serialization with an audit mixin, and each parent needs to contribute to `save`.

### 2.2 Preferred form

```python
class BaseStore:
    def save(self, record: dict[str, object]) -> None:
        print("stored", record)


class JsonStore(BaseStore):
    def save(self, record: dict[str, object]) -> None:
        print("serialized")
        super().save(record)


class AuditMixin(BaseStore):
    def save(self, record: dict[str, object]) -> None:
        print("audited")
        super().save(record)


class AuditedJsonStore(AuditMixin, JsonStore):
    pass


AuditedJsonStore().save({"id": 7})
```

### 2.3 Hazardous form

```python
class BaseStore:
    def save(self, record: dict[str, object]) -> None:
        print("stored", record)


class JsonStore(BaseStore):
    def save(self, record: dict[str, object]) -> None:
        print("serialized")
        BaseStore.save(self, record)


class AuditMixin(BaseStore):
    def save(self, record: dict[str, object]) -> None:
        print("audited")
        BaseStore.save(self, record)


class AuditedJsonStore(AuditMixin, JsonStore):
    pass


AuditedJsonStore().save({"id": 7})
```

### 2.4 Why this difference matters

Hard-coding `BaseStore.save` bypasses the next class in the method resolution order, so `JsonStore.save` never serializes the audited record. Cooperative `super()` lets every compatible parent participate once.

## 3. Boundaries and distinctions

Direct parent calls are reasonable for intentionally non-cooperative hierarchies. When a class is meant to compose with mixins, every cooperating override needs compatible signatures and `super()`.
