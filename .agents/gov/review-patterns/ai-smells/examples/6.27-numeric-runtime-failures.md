# Numeric/runtime failures

## 1. Catalog record

- **Catalog identifier:** 6.27
- **Evidence:** e
- **Definition:** Overflow, out-of-bounds access, division by zero, invalid values, recursion failure, or analogous runtime faults.

## 2. Scenario

### 2.1 Context

A reporting function calculates a conversion rate from completed and attempted jobs.

### 2.2 Safer approach

The agent defines behavior when no jobs were attempted and checks the denominator before division.

### 2.3 Failure mode

It computes `completed / attempted` when `attempted` can be zero.

### 2.4 Why this difference matters

A normal operational condition crashes the report instead of producing its defined result.

## 3. Boundaries and distinctions

This collects runtime faults such as numeric and bounds errors; an invalid source construct is a syntax or compile-time failure.
