# Understand TypedArray numeric coercion

## 1. Catalog record

- **Catalog identifier:** 4.1.8
- **Impact:** medium
- **Consensus:** high
- **Definition:** Typed arrays store values according to their fixed-width element type. Values may be truncated, wrapped, clamped, or rounded rather than preserved like ordinary JavaScript numbers.

## 2. Example

### 2.1 Scenario

A pixel writer must store an alpha channel value in the 0 through 255 range.

### 2.2 Preferred form

```javascript
function setAlpha(alpha) {
  if (!Number.isInteger(alpha) || alpha < 0 || alpha > 255) {
    throw new RangeError("Alpha must be an integer from 0 through 255");
  }
  const pixel = new Uint8Array(1);
  pixel[0] = alpha;
  return pixel[0];
}

console.log(setAlpha(255));
```

### 2.3 Hazardous form

```javascript
const pixel = new Uint8Array(1);
pixel[0] = 300;

console.log(pixel[0]);
```

### 2.4 Why this difference matters

The `Uint8Array` wraps 300 into an 8-bit value, silently storing 44 instead of the requested alpha value.

## 3. Boundaries and distinctions

Typed-array coercion is useful when a binary format intentionally requires it. Validate values first when silent wrapping, truncation, clamping, or rounding would violate the data contract.
