# Distinguish encodeURI from encodeURIComponent

## 1. Catalog record

- **Catalog identifier:** 10.1.9
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use encodeURIComponent for components and reserve encodeURI for complete URIs with structural delimiters.

## 2. Example

### 2.1 Scenario

A redirect page places a user-provided destination URL inside a query parameter.

### 2.2 Preferred form

```javascript
function redirectLink(destination) {
  return `/login?next=${encodeURIComponent(destination)}`;
}

console.log(redirectLink("/reports?team=red&range=week"));
```

### 2.3 Hazardous form

```javascript
function redirectLink(destination) {
  return `/login?next=${encodeURI(destination)}`;
}

console.log(redirectLink("/reports?team=red&range=week"));
```

### 2.4 Why this difference matters

`encodeURI()` leaves URI delimiters such as `?` and `&` intact, allowing the destination’s query string to alter the outer login URL.

## 3. Boundaries and distinctions

Use `encodeURI()` only for a complete URI whose delimiters are already intentional. Prefer the `URL` API when constructing a full URL from multiple components.
