# Exception translation without semantic value

## 1. Catalog record

- **Catalog identifier:** 6.19
- **Evidence:** se
- **Definition:** Introduces layers of custom error types that convey no additional information.

## 2. Scenario

### 2.1 Context

A repository calls a database driver that can raise a connection error.

### 2.2 Safer approach

The agent preserves the driver error or maps it once to the service's documented domain error with useful context.

### 2.3 Failure mode

It wraps the error successively as `DataError`, `RepositoryError`, and `StorageError`, each with the same message.

### 2.4 Why this difference matters

The added hierarchy hides the actionable cause without changing handling or recovery.

## 3. Boundaries and distinctions

An error boundary can justify translation when callers need a new, meaningful contract or recovery decision.
