# Mutating a dict while iterating it

## 1. Catalog record

- **Catalog identifier:** 6.11.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Do not add or remove dictionary entries while directly iterating the dictionary or its dynamic views. Iterate a copy or construct the desired result separately.

## 2. Example

### 2.1 Scenario

A cleanup step removes inactive users from an in-memory mapping.

### 2.2 Preferred form

```python
users = {"ana": True, "ben": False}
for name, active in list(users.items()):
    if not active:
        del users[name]
print(users)  # {'ana': True}
```

### 2.3 Hazardous form

```python
users = {"ana": True, "ben": False}
for name, active in users.items():
    if not active:
        del users[name]
```

### 2.4 Why this difference matters

Removing an entry changes the mapping's size while its dynamic view is being traversed, which can raise `RuntimeError`.

## 3. Boundaries and distinctions

Changing the value of an existing key can be safe when it does not alter the mapping's size, but build a separate result when that is clearer.
