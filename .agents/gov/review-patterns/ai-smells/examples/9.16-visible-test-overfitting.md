# Visible-test overfitting

## 1. Catalog record

- **Catalog identifier:** 9.16
- **Evidence:** a
- **Definition:** Passes exposed validation while failing held-out behavior.

## 2. Scenario

### 2.1 Context

A function must validate international phone numbers under the supplied contract.

### 2.2 Safer approach

Implement the stated validation rules and consider boundaries not represented by the visible examples.

### 2.3 Failure mode

Tune the function until the exposed test strings pass, without checking the actual specification.

### 2.4 Why this difference matters

Hidden and production inputs reveal that the implementation was fitted to test data instead of the required behavior.

## 3. Boundaries and distinctions

Visible tests are useful evidence, but they complement rather than define the full contract.
