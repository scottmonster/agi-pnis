# Beware the single-number Array constructor

## 1. Catalog record

- **Catalog identifier:** 3.1.4
- **Impact:** medium
- **Consensus:** high
- **Definition:** `Array(5)` creates an array with length 5 and no actual elements, not `[5]`. Use `[5]` for one value or `Array.of(5)` when constructor-style creation is required.

## 2. Example

### 2.1 Scenario

A configuration stores one retry-delay value in an array for a batching API.

### 2.2 Preferred form

```javascript
const retryDelays = [5];

console.log(retryDelays.length); // 1
console.log(retryDelays[0]); // 5
```

### 2.3 Hazardous form

```javascript
const retryDelays = Array(5);

console.log(retryDelays.length); // 5
console.log(retryDelays[0]); // undefined
```

### 2.4 Why this difference matters

The one-number `Array` overload interprets its argument as length, producing empty slots instead of a single element.

## 3. Boundaries and distinctions

`Array(5)` can intentionally allocate a sparse array length. Use `[5]` or `Array.of(5)` when the number itself is data.
