# Reads entire datasets/files when streaming would naturally fit the actual use case

## 1. Catalog record

- **Catalog identifier:** 7.11
- **Evidence:** se
- **Definition:** Materializes all input even though it can be processed incrementally, increasing latency and peak memory.

## 2. Scenario

### 2.1 Context

An agent adds a command that filters a multi-gigabyte log file and writes matching lines to another file.

### 2.2 Safer approach

It reads and writes line by line, retaining only the current line and required filter state.

### 2.3 Failure mode

It reads the complete log into memory before examining any line.

### 2.4 Why this difference matters

The command delays its first output and can fail from high peak memory use.

## 3. Boundaries and distinctions

Whole-input processing can be appropriate when the algorithm requires global access; streaming is relevant where incremental processing naturally fits the actual use case.
