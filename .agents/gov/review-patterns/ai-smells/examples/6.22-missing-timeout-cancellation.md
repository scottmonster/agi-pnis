# Missing timeout/cancellation

## 1. Catalog record

- **Catalog identifier:** 6.22
- **Evidence:** se
- **Definition:** Network/subprocess/async work can wait indefinitely.

## 2. Scenario

### 2.1 Context

An HTTP request handler calls an internal reporting service.

### 2.2 Safer approach

The agent applies the service's timeout and propagates request cancellation to the outbound call.

### 2.3 Failure mode

It awaits the reporting response with no timeout or cancellation path.

### 2.4 Why this difference matters

A stalled dependency can retain request capacity indefinitely and cascade into an outage.

## 3. Boundaries and distinctions

The proper limit depends on the operation and service contract; short work does not justify an arbitrary timeout that breaks valid requests.
