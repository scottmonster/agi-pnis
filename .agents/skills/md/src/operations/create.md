# Create

Create a new Markdown artifact from the user's request and any authoritative inputs they provide.

## Establish the target

1. Determine the purpose, audience, intended behavior, authority, available inputs, file type, and applicable file-type requirements.
2. Select only content that materially serves the artifact's purpose.
3. Identify what governs, directs, states, supports, or illustrates before choosing presentation. Organize content around authority, dependency, execution, scope, priority, and comprehension.
4. Do not invent requirements, decisions, constraints, exceptions, authority, relationships, or unsupported detail.
5. Preserve material uncertainty. Resolve ambiguity only when the inputs support a resolution, and surface unresolved conflict or ambiguity when it affects correct use.
6. Validate the result and correct defects that affect meaning, structure, or usability. Repeat affected earlier steps when a correction changes meaning or composition.

Missing information does not authorize invention.
Omit unavailable detail when the artifact remains correct and usable without it.
