# Use performance.now for elapsed-time measurement

## 1. Catalog record

- **Catalog identifier:** 12.1.5
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use performance.now when browser elapsed-time measurement requires a monotonic clock.

## 2. Example

### 2.1 Scenario

A browser reports how long a user action took while other code and the operating system may adjust the wall clock.

### 2.2 Preferred form

```javascript
async function measureSave(saveDraft) {
  const startedAt = performance.now();
  await saveDraft();
  return performance.now() - startedAt;
}
```

### 2.3 Hazardous form

```javascript
async function measureSave(saveDraft) {
  const startedAt = Date.now();
  await saveDraft();
  return Date.now() - startedAt;
}
```

### 2.4 Why this difference matters

`Date.now()` follows the system clock, so a clock correction can make a duration jump forward, backward, or negative. `performance.now()` advances monotonically for reliable elapsed-time measurements.

## 3. Boundaries and distinctions

Use `Date.now()` when you need a wall-clock timestamp to store or exchange. `performance.now()` is for measuring intervals and is not an absolute date.
