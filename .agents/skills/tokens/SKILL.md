# Tokens

Count tokens locally with `bash src/scripts/count-tokens.sh`. This script uses `tiktoken-cli`; it does not make an API request.

## Use

```sh
bash .agents/skills/tokens/src/scripts/count-tokens.sh --model <running-model> path/to/file.md
printf 'Text to count' | bash .agents/skills/tokens/src/scripts/count-tokens.sh --model <running-model>
```

Use the model currently running this skill. Pass that model explicitly with `--model`; do not use a default model or substitute a model selected by the user.

Look up the running model in the table below. If it is not listed, the counter uses the listed model with the nearest encoding, using the closest model family and version as the tiebreaker. For example, `gpt-5.6` resolves to `gpt-5`, which uses `o200k_base`. State when this fallback is used.

Report the running model, the model the counter used, its encoding, and the token count. State that counts are specific to the selected encoding.

## `/tokens update`

When the user invokes `/tokens update`, load and run [src/update](src/update). It discovers the local `tiktoken-cli` through the specified failover sequence, discovers the installed `model_to_encoding.json`, and regenerates the machine-readable mapping and the table in this file. Report this skill file and the number of discovered models.
