# Incompatible type use

## 1. Catalog record

- **Catalog identifier:** 6.9
- **Evidence:** e
- **Definition:** Passes, assigns, compares, or operates on a value where its type or representation is not accepted.

## 2. Scenario

### 2.1 Context

A database function requires a `Date` object for an expiration field.

### 2.2 Safer approach

The agent converts the validated ISO string into a `Date` before calling the function.

### 2.3 Failure mode

It passes the raw string to a function that accepts only a `Date`.

### 2.4 Why this difference matters

The operation may be rejected or persist data with an invalid representation.

## 3. Boundaries and distinctions

The value exists and may be initialized, but the receiving operation does not accept its type or representation.
