# Task-or-External Prevention Locus

## 1. Example failures

- **Conflicting requirements:** The task requires mutually incompatible outcomes, and no authorized party is available to resolve the conflict. Clarify or defer the task until authority is available.
- **Missing acceptance criteria:** The request does not state which behavior is required, leading to a result the requester rejects despite reasonable implementation. Obtain acceptance criteria or document the limitation.
- **Unavailable external dependency:** A required package registry is unavailable, preventing a reproducible build. Repair or wait for the external dependency, or defer the work with the limitation recorded.
