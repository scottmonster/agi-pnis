# Use globalThis for portable access to the global object

## 1. Catalog record

- **Catalog identifier:** 8.1.5
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use globalThis for portable global-object access across hosts.

## 2. Example

### 2.1 Scenario

A shared library reads a host-provided application version in browsers, workers, and Node.js.

### 2.2 Preferred form

```javascript
function applicationVersion() {
  return globalThis.APP_VERSION ?? "development";
}

globalThis.APP_VERSION = "2026.09";
console.log(applicationVersion());
```

### 2.3 Hazardous form

```javascript
function applicationVersion() {
  return window.APP_VERSION ?? "development";
}

globalThis.APP_VERSION = "2026.09";
console.log(applicationVersion());
```

### 2.4 Why this difference matters

The hazardous code assumes a browser window. It throws in hosts such as Web Workers and Node.js where `window` is not defined.

## 3. Boundaries and distinctions

`globalThis` identifies the global object, but host-specific APIs still need capability checks before use.
