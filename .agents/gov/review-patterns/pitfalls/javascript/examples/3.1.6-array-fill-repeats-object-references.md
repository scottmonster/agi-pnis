# Array.fill repeats object references

## 1. Catalog record

- **Catalog identifier:** 3.1.6
- **Impact:** medium
- **Consensus:** high
- **Definition:** `Array(n).fill({})` stores the same object reference in every position. Use a factory pattern such as `Array.from({length: n}, () => ({}))` when distinct objects are required.

## 2. Example

### 2.1 Scenario

A board needs independent state objects for each cell.

### 2.2 Preferred form

```javascript
const cells = Array.from({ length: 3 }, () => ({ occupied: false }));
cells[0].occupied = true;

console.log(cells.map((cell) => cell.occupied)); // [true, false, false]
```

### 2.3 Hazardous form

```javascript
const cells = Array(3).fill({ occupied: false });
cells[0].occupied = true;

console.log(cells.map((cell) => cell.occupied)); // [true, true, true]
```

### 2.4 Why this difference matters

`fill` repeats one reference, so changing one cell changes the object every array position points to.

## 3. Boundaries and distinctions

`fill` is safe for primitive values and is intentional when all positions should share one mutable object.
