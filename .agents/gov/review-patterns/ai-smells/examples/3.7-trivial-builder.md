# Trivial builder

## 1. Catalog record

- **Catalog identifier:** 3.7
- **Evidence:** se
- **Definition:** Introduces a builder for a small object whose constructor is already readable.

## 2. Scenario

### 2.1 Context

A request produces a `Report(title, date, owner)` object.

### 2.2 Safer approach

Use the readable constructor or a small named constructor if names need clarification.

### 2.3 Failure mode

Require `ReportBuilder().withTitle(title).withDate(date).withOwner(owner).build()` for the same three fields.

### 2.4 Why this difference matters

The builder adds ceremony and mutable intermediate state while making a simple value harder to scan.

## 3. Boundaries and distinctions

Builders can help with complex optional construction or validation; they are not automatically clearer than a small constructor.
