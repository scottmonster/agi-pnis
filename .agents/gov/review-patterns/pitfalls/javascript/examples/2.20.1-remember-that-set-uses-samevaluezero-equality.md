# Remember that Set uses SameValueZero equality

## 1. Catalog record

- **Catalog identifier:** 2.20.1
- **Impact:** low
- **Consensus:** high
- **Definition:** Account for SameValueZero and object identity semantics when using Set membership.

## 2. Example

### 2.1 Scenario

A deduplication step must recognize repeated `NaN` measurements.

### 2.2 Preferred form

```javascript
const measurements = new Set([NaN]);

console.log(measurements.has(NaN));
```

### 2.3 Hazardous form

```javascript
const measurements = new Set([{ value: 1 }]);

console.log(measurements.has({ value: 1 }));
```

### 2.4 Why this difference matters

Set uses SameValueZero: `NaN` matches itself and `-0` matches `0`, but objects match only the same reference, not equal-looking objects.

## 3. Boundaries and distinctions

Normalize to stable primitive keys or implement a structural comparison when collection membership must use object content.
