# Boolean HTML attributes are controlled by presence

## 1. Catalog record

- **Catalog identifier:** 11.1.10
- **Impact:** medium
- **Consensus:** high
- **Definition:** Represent false by removing a Boolean HTML attribute, not by assigning the string false.

## 2. Example

### 2.1 Scenario

A form enables or disables its Submit button after validating its fields.

### 2.2 Preferred form

```javascript
const submitButton = document.querySelector("button[type=submit]");
const formIsValid = true;

submitButton.toggleAttribute("disabled", !formIsValid);
```

### 2.3 Hazardous form

```javascript
const submitButton = document.querySelector("button[type=submit]");
const formIsValid = true;

submitButton.setAttribute("disabled", String(!formIsValid));
```

### 2.4 Why this difference matters

`disabled="false"` still has the `disabled` attribute, so the browser treats the button as disabled even when the string says false.

## 3. Boundaries and distinctions

For reflected Boolean DOM properties, setting `submitButton.disabled = false` also removes the corresponding Boolean attribute.
