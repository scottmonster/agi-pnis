# Do not use for...in as an array iterator

## 1. Catalog record

- **Catalog identifier:** 3.1.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `for...of`, array methods, or indexed iteration for array values. `for...in` enumerates string property names and includes enumerable properties from the prototype chain.

## 2. Example

### 2.1 Scenario

A report generator needs each numeric score in an array, even when another script has added an enumerable prototype property.

### 2.2 Preferred form

```javascript
const scores = [7, 9];
const total = scores.reduce((sum, score) => sum + score, 0);

console.log(total); // 16
```

### 2.3 Hazardous form

```javascript
Array.prototype.reportLabel = "draft";

const scores = [7, 9];
for (const index in scores) {
  console.log(scores[index]); // 7, 9, then "draft"
}

delete Array.prototype.reportLabel;
```

### 2.4 Why this difference matters

`for...in` iterates enumerable property names, including inherited ones, rather than just array values in a dependable array-iteration contract.

## 3. Boundaries and distinctions

`for...in` is appropriate for deliberately enumerating object properties with ownership checks where needed. It is not an array-value iterator.
