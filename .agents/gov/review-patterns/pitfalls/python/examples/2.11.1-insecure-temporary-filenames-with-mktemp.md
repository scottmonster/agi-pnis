# Insecure temporary filenames with `mktemp()`

## 1. Catalog record

- **Catalog identifier:** 2.11.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Do not use `tempfile.mktemp()` to create security-sensitive temporary files. Use `TemporaryFile`, `NamedTemporaryFile`, `mkstemp`, or `TemporaryDirectory`.

## 2. Example

### 2.1 Scenario

A command writes sensitive report data to a temporary file before passing its path to another process.

### 2.2 Preferred form

```python
import os
import tempfile


def write_report(data: str) -> str:
    descriptor, path = tempfile.mkstemp(prefix="report-", suffix=".txt")
    with os.fdopen(descriptor, "w", encoding="utf-8") as report:
        report.write(data)
    return path
```

### 2.3 Hazardous form

```python
import tempfile


def write_report(data: str) -> str:
    path = tempfile.mktemp(prefix="report-", suffix=".txt")
    with open(path, "w", encoding="utf-8") as report:
        report.write(data)
    return path
```

### 2.4 Why this difference matters

`mktemp()` chooses a name without creating the file. Another process can claim or replace that path before the later `open()`.

## 3. Boundaries and distinctions

For non-path-based temporary work, `TemporaryFile()` is often simpler because it manages both creation and cleanup.
