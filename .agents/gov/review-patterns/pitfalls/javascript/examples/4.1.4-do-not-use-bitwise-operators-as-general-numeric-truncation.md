# Do not use bitwise operators as general numeric truncation

## 1. Catalog record

- **Catalog identifier:** 4.1.4
- **Impact:** medium
- **Consensus:** high
- **Definition:** Avoid tricks such as `x | 0` or `x << 0` when general JavaScript numbers are intended. Use `Math.trunc()` for truncation.

## 2. Example

### 2.1 Scenario

A reporting tool removes the fractional part of a visitor count that may exceed 32-bit integer range.

### 2.2 Preferred form

```javascript
function wholeVisitors(count) {
  return Math.trunc(count);
}

console.log(wholeVisitors(4_500_000_000.8));
```

### 2.3 Hazardous form

```javascript
function wholeVisitors(count) {
  return count | 0;
}

console.log(wholeVisitors(4_500_000_000.8));
```

### 2.4 Why this difference matters

The bitwise operator converts the value to a signed 32-bit integer before truncating, discarding higher bits and producing a different count.

## 3. Boundaries and distinctions

Bitwise operators are appropriate when 32-bit integer bit manipulation is the intended operation. They are not general-purpose numeric truncation.
