# Connection/infrastructure conflict

## 1. Catalog record

- **Catalog identifier:** 2.14
- **Evidence:** e
- **Definition:** Assumes services, ports, queues, databases, credentials, URLs, or deployment topology not present.

## 2. Scenario

### 2.1 Context

A worker must publish a notification after an order is accepted.

### 2.2 Safer approach

The agent inspects deployment configuration and existing service clients, then uses the available notification mechanism.

### 2.3 Failure mode

It publishes to `amqp://rabbitmq:5672/orders`, assuming a RabbitMQ broker and credentials exist in every environment.

### 2.4 Why this difference matters

The new path cannot connect in the actual deployment topology and may block or fail production processing.

## 3. Boundaries and distinctions

This is about absent operational infrastructure, whereas a project dependency conflict concerns unavailable code-level dependencies or initialization paths.
