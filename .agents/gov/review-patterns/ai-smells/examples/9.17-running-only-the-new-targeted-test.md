# Running only the new/targeted test

## 1. Catalog record

- **Catalog identifier:** 9.17
- **Evidence:** a
- **Definition:** Never checks the existing regression suite.

## 2. Scenario

### 2.1 Context

A shared date parser is changed to support a new locale.

### 2.2 Safer approach

Run the new locale test and the relevant existing parser suite before reporting completion.

### 2.3 Failure mode

Run only the one newly added locale test and stop when it passes.

### 2.4 Why this difference matters

The change can break older date formats without any verification of the regression surface.

## 3. Boundaries and distinctions

Verification should be proportionate to change scope; a targeted test may be sufficient only when there is credible evidence that no broader contract can be affected.
