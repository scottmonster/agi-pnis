# Implicit text-file encoding

## 1. Catalog record

- **Catalog identifier:** 7.6.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Specify the encoding for files whose format has a defined encoding, typically UTF-8, instead of relying on the interpreter or platform default.

## 2. Example

### 2.1 Scenario

A program reads a UTF-8 configuration file on several platforms.

### 2.2 Preferred form

```python
from pathlib import Path

config = Path("config.txt").read_text(encoding="utf-8")
print(config)
```

### 2.3 Hazardous form

```python
from pathlib import Path

config = Path("config.txt").read_text()
print(config)
```

### 2.4 Why this difference matters

The hazardous form depends on the process default encoding, which can differ by platform, locale, or runtime configuration.

## 3. Boundaries and distinctions

Omit an encoding only when the format intentionally follows the environment default and that dependency is part of the contract.
