# Use strict mode or ES modules instead of sloppy mode

## 1. Catalog record

- **Catalog identifier:** 1.1.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Prefer ES modules, which are strict automatically, or `"use strict"` for classic scripts. Strict mode converts several silent mistakes into errors and removes historically problematic behavior.

## 2. Example

### 2.1 Scenario

A browser utility is maintained as a classic script while it is gradually moved into modules.

### 2.2 Preferred form

```javascript
"use strict";

function recordVisit() {
  const page = "settings";
  return page;
}

console.log(recordVisit());
```

### 2.3 Hazardous form

```javascript
function recordVisit() {
  page = "settings";
  return page;
}

console.log(recordVisit());
```

### 2.4 Why this difference matters

The hazardous classic script silently creates a global `page`; strict mode turns that accidental assignment into an immediate error.

## 3. Boundaries and distinctions

ES modules are strict by default, so they do not need the directive. The directive is still relevant to non-module scripts.
