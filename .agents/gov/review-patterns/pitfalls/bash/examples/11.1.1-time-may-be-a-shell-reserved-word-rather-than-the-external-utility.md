# `time` may be a shell reserved word rather than the external utility

## 1. Catalog record

- **Catalog identifier:** 11.1.1
- **Impact:** low
- **Consensus:** high
- **Definition:** Bash has a `time` reserved word that can time pipelines and has shell-specific formatting behavior. If a script specifically requires an external `time` implementation and its options, invoke that implementation deliberately.

## 2. Example

### 2.1 Scenario

A benchmark script needs the GNU `time` utility's `-f` formatting option for a machine-readable report.

### 2.2 Preferred form

```bash
#!/usr/bin/env bash

/usr/bin/time -f 'elapsed=%e seconds' sleep 1
```

### 2.3 Hazardous form

```bash
#!/usr/bin/env bash

time -f 'elapsed=%e seconds' sleep 1
```

### 2.4 Why this difference matters

The unqualified command can use Bash's `time` reserved word, which does not implement the external utility's options or output format.

## 3. Boundaries and distinctions

Use the reserved word when shell timing behavior is sufficient. An explicit external path is needed only when the script depends on a particular utility implementation and its options.
