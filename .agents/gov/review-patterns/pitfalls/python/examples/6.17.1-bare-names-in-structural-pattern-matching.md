# Bare names in structural pattern matching

## 1. Catalog record

- **Catalog identifier:** 6.17.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** In `case` patterns, do not write a bare identifier when intending to compare against an existing constant. Use a literal or qualified value pattern.

## 2. Example

### 2.1 Scenario

A command handler must recognize only the configured stop token.

### 2.2 Preferred form

```python
from enum import Enum

class Token(Enum):
    STOP = "stop"

value = Token.STOP
match value:
    case Token.STOP:
        print("halt")
```

### 2.3 Hazardous form

```python
STOP = "stop"
value = "continue"
match value:
    case STOP:
        print(STOP)  # Captures 'continue' instead of comparing it.
```

### 2.4 Why this difference matters

A bare identifier is a capture pattern, so it matches any value and binds that value instead of testing the existing constant.

## 3. Boundaries and distinctions

Use a bare name when capturing an arbitrary matched value is the intended pattern behavior.
