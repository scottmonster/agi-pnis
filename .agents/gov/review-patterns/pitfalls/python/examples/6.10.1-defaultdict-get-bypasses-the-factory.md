# `defaultdict.get()` bypasses the factory

## 1. Catalog record

- **Catalog identifier:** 6.10.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Do not expect `defaultdict.get(key)` to create a missing entry. Use indexing when invoking the factory is intended.

## 2. Example

### 2.1 Scenario

A counter records requests by endpoint and must create a count before incrementing it.

### 2.2 Preferred form

```python
from collections import defaultdict

counts = defaultdict(int)
counts["/health"] += 1
print(counts["/health"])  # 1
```

### 2.3 Hazardous form

```python
from collections import defaultdict

counts = defaultdict(int)
count = counts.get("/health")
print(count)  # None
```

### 2.4 Why this difference matters

`get()` follows ordinary dictionary behavior and returns `None` for a missing key without calling `default_factory`.

## 3. Boundaries and distinctions

Use `get()` when probing without creating an entry is the goal, optionally supplying an explicit fallback such as `counts.get(path, 0)`.
