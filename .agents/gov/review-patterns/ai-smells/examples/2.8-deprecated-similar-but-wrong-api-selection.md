# Deprecated/similar-but-wrong API selection

## 1. Catalog record

- **Catalog identifier:** 2.8
- **Evidence:** e
- **Definition:** Uses an older or superficially similar API inappropriate to the actual environment.

## 2. Scenario

### 2.1 Context

A project uses the current router package and needs to navigate after a successful form submission.

### 2.2 Safer approach

The agent checks the installed router version and adopts the navigation API already used in current components.

### 2.3 Failure mode

It imports an older navigation hook from a tutorial written for a previous major release.

### 2.4 Why this difference matters

The code may not build, or it may introduce behavior and dependencies inconsistent with the actual runtime.

## 3. Boundaries and distinctions

An older API is not inherently wrong; it is wrong when it does not fit the project's installed environment or supported compatibility target.
