# Object.defineProperty descriptor defaults are false

## 1. Catalog record

- **Catalog identifier:** 2.10.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Set descriptor flags explicitly because omitted flags default to false.

## 2. Example

### 2.1 Scenario

A library adds a configurable public version property.

### 2.2 Preferred form

```javascript
const library = {};
Object.defineProperty(library, "version", {
  value: "1.0.0",
  writable: true,
  enumerable: true,
  configurable: true,
});
```

### 2.3 Hazardous form

```javascript
const library = {};
Object.defineProperty(library, "version", {
  value: "1.0.0",
});

library.version = "1.1.0";
```

### 2.4 Why this difference matters

Omitted descriptor flags default to `false`, making the hazardous property non-writable, non-enumerable, and non-configurable.

## 3. Boundaries and distinctions

Non-writable or hidden properties can be intentional. State every relevant flag so the constraints are visible to readers.
