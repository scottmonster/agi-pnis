# Missing edge/corner case

## 1. Catalog record

- **Catalog identifier:** 6.4
- **Evidence:** e
- **Definition:** Empty values, boundaries, duplicate values, negative cases, zero, null, overflow, or unusual ordering break the implementation.

## 2. Scenario

### 2.1 Context

A helper returns the average score for a list of completed reviews.

### 2.2 Safer approach

The agent defines the empty-list behavior with the caller and handles it before dividing by the count.

### 2.3 Failure mode

It divides the sum by `len(scores)` without considering an empty list.

### 2.4 Why this difference matters

A legitimate zero-review account causes a runtime error.

## 3. Boundaries and distinctions

The normal calculation is correct; the defect arises at a supported boundary condition.
