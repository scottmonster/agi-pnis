# Assuming `and` and `or` return booleans

## 1. Catalog record

- **Catalog identifier:** 6.20.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Remember that `and` and `or` return one of their operands. Avoid `value or default` when valid falsey values such as `0`, `""`, or `[]` must be preserved.

## 2. Example

### 2.1 Scenario

A request's timeout may legitimately be zero and should not be replaced by the standard timeout.

### 2.2 Preferred form

```python
provided_timeout = 0
timeout = 30 if provided_timeout is None else provided_timeout
print(timeout)  # 0
```

### 2.3 Hazardous form

```python
provided_timeout = 0
timeout = provided_timeout or 30
print(timeout)  # 30
```

### 2.4 Why this difference matters

`or` returns its second operand when the first is falsey, so it silently replaces valid data instead of simply returning a boolean.

## 3. Boundaries and distinctions

`value or default` is concise and appropriate when every falsey value should intentionally select the fallback.
