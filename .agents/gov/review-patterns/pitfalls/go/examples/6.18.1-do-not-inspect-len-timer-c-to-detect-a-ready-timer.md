# Do not inspect `len(timer.C)` to detect a ready timer

## 1. Catalog record

- **Catalog identifier:** 6.18.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use a nonblocking `select` rather than testing timer-channel length.

## 2. Example

### 2.1 Scenario

A retry loop checks whether its delay elapsed.

### 2.2 Preferred form

```go
package main

import "time"

func expired(timer *time.Timer) bool { select { case <-timer.C: return true; default: return false } }
```

### 2.3 Hazardous form

```go
package main

import "time"

func expired(timer *time.Timer) bool { return len(timer.C) > 0 }
```

### 2.4 Why this difference matters

Timer-channel length is not a readiness test. A nonblocking receive performs the operation that matters.

## 3. Boundaries and distinctions

The preferred form consumes the timer event. Coordinate ownership when several goroutines could receive it.
