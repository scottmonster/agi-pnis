# Do not mistake shallow copying for independent object state

## 1. Catalog record

- **Catalog identifier:** 2.12.2
- **Impact:** high
- **Consensus:** high
- **Definition:** Clone or reconstruct nested references that need independent state.

## 2. Example

### 2.1 Scenario

A request template must provide each caller with an independent headers object.

### 2.2 Preferred form

```javascript
const template = { headers: { accept: "application/json" } };
const request = {
  ...template,
  headers: { ...template.headers },
};

request.headers.accept = "text/plain";
console.log(template.headers.accept);
```

### 2.3 Hazardous form

```javascript
const template = { headers: { accept: "application/json" } };
const request = { ...template };

request.headers.accept = "text/plain";
console.log(template.headers.accept);
```

### 2.4 Why this difference matters

Object spread copies only the outer object, leaving `request.headers` and `template.headers` as the same nested object.

## 3. Boundaries and distinctions

A shallow copy is sufficient when nested values are immutable or intentionally shared. Reconstruct only the state that needs ownership separation.
