# Avoid pointers merely to reduce value-copy size

## 1. Catalog record

- **Catalog identifier:** 13.9.1
- **Impact:** low
- **Consensus:** high
- **Definition:** Pass small immutable values such as strings and interface values directly unless pointer semantics are actually required.

## 2. Example

### 2.1 Scenario

A formatter receives a small immutable label and only needs to read it.

### 2.2 Preferred form

```go
package example

func labelFor(name string) string {
	return "user: " + name
}
```

### 2.3 Hazardous form

```go
package example

func labelFor(name *string) string {
	return "user: " + *name
}
```

### 2.4 Why this difference matters

Passing the string directly expresses that the function only needs its value and permits a simple call. The pointer form adds nil handling and aliasing concerns without avoiding a meaningful copy.

## 3. Boundaries and distinctions

Use pointers when mutation, identity, optionality, or copying a large value is part of the function's actual contract.
