# Logging every step instead of logging operationally meaningful events

## 1. Catalog record

- **Catalog identifier:** 12.7
- **Evidence:** se
- **Definition:** Emits routine internal activity rather than decision, error, audit, or lifecycle events useful for operating the system.

## 2. Scenario

### 2.1 Context

An order worker logs every loop iteration, variable assignment, and successful queue poll, but does not clearly log rejected orders or retry exhaustion.

### 2.2 Safer approach

Log meaningful lifecycle transitions, decisions, failures, and audit events with enough context to operate and diagnose the worker.

### 2.3 Failure mode

Add debug-style messages for routine steps at normal log level and assume the volume provides observability.

### 2.4 Why this difference matters

Routine noise raises storage and search costs while obscuring the few signals an operator needs during an incident.

## 3. Boundaries and distinctions

Temporary detailed tracing can be useful when scoped and controlled. This failure concerns routine production telemetry that substitutes activity noise for operational events.
