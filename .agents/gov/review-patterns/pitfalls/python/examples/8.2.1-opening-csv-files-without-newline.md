# Opening CSV files without `newline=""`

## 1. Catalog record

- **Catalog identifier:** 8.2.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Open files passed to `csv.reader` or `csv.writer` with `newline=""`.

## 2. Example

### 2.1 Scenario

A report generator writes CSV rows that must use the CSV module's newline handling on every supported platform.

### 2.2 Preferred form

```python
import csv
from pathlib import Path

path = Path("report.csv")
with path.open("w", encoding="utf-8", newline="") as stream:
    writer = csv.writer(stream)
    writer.writerow(["customer", "total"])
    writer.writerow(["Ada", "42"])
```

### 2.3 Hazardous form

```python
import csv
from pathlib import Path

path = Path("report.csv")
with path.open("w", encoding="utf-8") as stream:
    writer = csv.writer(stream)
    writer.writerow(["customer", "total"])
    writer.writerow(["Ada", "42"])
```

### 2.4 Why this difference matters

Without `newline=""`, platform text translation can interfere with CSV's own newline handling and produce incorrect line endings or blank rows.

## 3. Boundaries and distinctions

This requirement applies when a real text file is passed to `csv.reader` or `csv.writer`. An in-memory stream can use its own documented newline behavior.
