# Wildcard imports

## 1. Catalog record

- **Catalog identifier:** 8.16.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Avoid `from module import *` outside narrowly controlled uses. Import explicit names or the module itself.

## 2. Example

### 2.1 Scenario

A calculation module needs square-root functionality while keeping the source of its names clear.

### 2.2 Preferred form

```python
import math

result = math.sqrt(81)

assert result == 9
```

### 2.3 Hazardous form

```python
from math import *

result = sqrt(81)

assert result == 9
```

### 2.4 Why this difference matters

Wildcard imports obscure where names come from and can overwrite names as modules evolve.

## 3. Boundaries and distinctions

Wildcard imports can be intentionally controlled in a package's re-export module or an interactive session.
