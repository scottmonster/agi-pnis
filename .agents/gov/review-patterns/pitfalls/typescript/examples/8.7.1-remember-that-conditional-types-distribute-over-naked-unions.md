# Remember that conditional types distribute over naked unions

## 1. Catalog record

- **Catalog identifier:** 8.7.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** `T extends U ? X : Y` distributes when `T` is a naked type parameter; wrap both sides in tuples such as `[T] extends [U]` when whole-union testing is intended.

## 2. Example

### 2.1 Scenario

A validation type must determine whether an entire union is assignable to `string`.

### 2.2 Preferred form

```typescript
type IsEntirelyString<T> = [T] extends [string] ? true : false;

const valid: IsEntirelyString<'draft' | 'published'> = true;
const invalid: IsEntirelyString<string | number> = false;
```

### 2.3 Hazardous form

```typescript
type IsString<T> = T extends string ? true : false;

const result: IsString<string | number> = false; // type is boolean, not false
```

### 2.4 Why this difference matters

Unintended distributivity can produce radically different and much larger resulting types.

## 3. Boundaries and distinctions

Apply this guidance in the conditions described by the catalog record. Deliberate exceptions need a documented runtime guarantee, compatible toolchain behavior, or an explicit local unsafe boundary.
