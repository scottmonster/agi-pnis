# `argparse` with `type=bool`

## 1. Catalog record

- **Catalog identifier:** 8.11.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Do not parse boolean command-line options using `type=bool`. Use actions such as `store_true`, `store_false`, `BooleanOptionalAction`, or an explicit text parser.

## 2. Example

### 2.1 Scenario

A command accepts an optional switch that enables detailed output.

### 2.2 Preferred form

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("--verbose", action=argparse.BooleanOptionalAction, default=False)
arguments = parser.parse_args(["--no-verbose"])

assert arguments.verbose is False
```

### 2.3 Hazardous form

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("--verbose", type=bool)
arguments = parser.parse_args(["--verbose", "false"])

assert arguments.verbose is True
```

### 2.4 Why this difference matters

`bool("false")` is true because any nonempty string is truthy, so common command-line spellings are misparsed.

## 3. Boundaries and distinctions

An explicit converter can be appropriate when an option must accept textual values beyond standard boolean flags.
