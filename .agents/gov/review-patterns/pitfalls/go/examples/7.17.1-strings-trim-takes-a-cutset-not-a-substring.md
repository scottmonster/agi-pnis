# `strings.Trim` takes a cutset, not a substring

## 1. Catalog record

- **Catalog identifier:** 7.17.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `TrimPrefix` or `TrimSuffix` when removing an exact prefix or suffix. `Trim` removes any leading and trailing rune contained in its cutset argument.

## 2. Example

### 2.1 Scenario

A protocol parser removes the exact `Bearer ` prefix from an authorization value.

### 2.2 Preferred form

```go
package auth

import "strings"

func token(value string) string {
	return strings.TrimPrefix(value, "Bearer ")
}
```

### 2.3 Hazardous form

```go
package auth

import "strings"

func token(value string) string {
	return strings.Trim(value, "Bearer ")
}
```

### 2.4 Why this difference matters

The hazardous call removes any leading or trailing `B`, `e`, `a`, `r`, or space, rather than one exact prefix.

## 3. Boundaries and distinctions

Use `Trim` when removing a set of boundary runes, such as whitespace or quote characters, is the intended operation.
