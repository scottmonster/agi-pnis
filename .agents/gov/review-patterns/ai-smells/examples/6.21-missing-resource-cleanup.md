# Missing resource cleanup

## 1. Catalog record

- **Catalog identifier:** 6.21
- **Evidence:** se
- **Definition:** Files, sockets, transactions, processes, locks, streams, or temporary resources leak.

## 2. Scenario

### 2.1 Context

A worker opens an uploaded archive to extract validated files.

### 2.2 Safer approach

The agent uses the language's scoped resource construct so the archive closes even when extraction fails.

### 2.3 Failure mode

It opens the archive and returns early on an invalid entry without closing it.

### 2.4 Why this difference matters

Repeated jobs can exhaust file descriptors or retain locks that disrupt later work.

## 3. Boundaries and distinctions

Ownership matters: a function should clean up resources it acquires, while a caller may own a resource passed in for continued use.
