# Reading immediately after `copyfileobj()` without flushing

## 1. Catalog record

- **Catalog identifier:** 15.4.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Flush or close the destination before immediately consuming data written through `shutil.copyfileobj()`.

## 2. Example

### 2.1 Scenario

A program copies an uploaded stream into a buffered file and then immediately passes the file to a parser.

### 2.2 Preferred form

```python
import io
import shutil


def copied_text(source: io.BytesIO) -> str:
    destination = io.BytesIO()
    shutil.copyfileobj(source, destination)
    destination.flush()
    destination.seek(0)
    return destination.read().decode("utf-8")
```

### 2.3 Hazardous form

```python
import io
import shutil


def copied_text(source: io.BytesIO) -> str:
    raw_destination = io.BytesIO()
    destination = io.BufferedWriter(raw_destination)
    shutil.copyfileobj(source, destination)
    return raw_destination.getvalue().decode("utf-8")
```

### 2.4 Why this difference matters

`copyfileobj()` does not promise to flush a buffered destination. A following consumer can see incomplete data unless the writer is flushed or closed first.

## 3. Boundaries and distinctions

An unbuffered destination may not need an explicit flush. Flush or close whenever later work depends on buffered bytes becoming visible.
