# Comparing sequence length with zero

## 1. Catalog record

- **Catalog identifier:** 16.2.1
- **Impact:** low
- **Consensus:** high
- **Definition:** Prefer `if sequence:` or `if not sequence:` when testing emptiness rather than explicitly comparing `len(sequence)` with zero.

## 2. Example

### 2.1 Scenario

A queue consumer returns early when there are no pending messages.

### 2.2 Preferred form

```python
def first_message(messages: list[str]) -> str | None:
    if not messages:
        return None
    return messages[0]
```

### 2.3 Hazardous form

```python
def first_message(messages: list[str]) -> str | None:
    if len(messages) == 0:
        return None
    return messages[0]
```

### 2.4 Why this difference matters

Truth-value testing expresses the question directly and follows Python's container protocol. It also works with suitable objects that provide truthiness without a conventional length.

## 3. Boundaries and distinctions

Use `len()` when the numeric size itself matters, such as enforcing a minimum count. A truth-value test only distinguishes empty from nonempty.
