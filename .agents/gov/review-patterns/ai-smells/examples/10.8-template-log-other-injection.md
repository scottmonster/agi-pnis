# Template/log/other injection

## 1. Catalog record

- **Catalog identifier:** 10.8
- **Evidence:** e
- **Definition:** Lets untrusted data alter a template, log record, interpreter input, or downstream format instead of treating it as data.

## 2. Scenario

### 2.1 Context

An audit service records a caller-supplied display name with each login attempt.

### 2.2 Safer approach

Use structured logging with the name as a data field and encode or validate it for the consuming format.

### 2.3 Failure mode

The agent concatenates the display name into a line-oriented log message without handling control characters.

### 2.4 Why this difference matters

An attacker can forge or alter apparent log records, mislead investigations, or affect another downstream interpreter.

## 3. Boundaries and distinctions

The exact defense depends on the downstream format. This is broader than SQL or shell injection because the dangerous interpreter may be a template, log parser, or another formatter.
