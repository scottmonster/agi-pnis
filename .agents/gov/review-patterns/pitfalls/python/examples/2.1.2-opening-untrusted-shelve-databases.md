# Opening untrusted `shelve` databases

## 1. Catalog record

- **Catalog identifier:** 2.1.2
- **Impact:** high
- **Consensus:** high
- **Definition:** Do not open a `shelve` database obtained from an untrusted source.

## 2. Example

### 2.1 Scenario

An administrator imports settings exported by a customer into a local tool.

### 2.2 Preferred form

```python
import json
from pathlib import Path


def load_settings(path: Path) -> dict[str, str]:
    return json.loads(path.read_text(encoding="utf-8"))


print(load_settings(Path("settings.json")))
```

### 2.3 Hazardous form

```python
import shelve
from pathlib import Path


def load_settings(path: Path) -> object:
    with shelve.open(str(path)) as database:
        return database["settings"]


print(load_settings(Path("customer-upload")))
```

### 2.4 Why this difference matters

Shelve uses pickle for stored values, so opening a database supplied by a customer can execute attacker-controlled code.

## 3. Boundaries and distinctions

Shelve is suitable for simple trusted local persistence. Use a non-executable format for files that can cross a trust boundary.
