# `math.isclose()` against zero without `abs_tol`

## 1. Catalog record

- **Catalog identifier:** 7.1.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** When checking whether a value is sufficiently close to zero, provide a meaningful nonzero `abs_tol` rather than relying only on relative tolerance.

## 2. Example

### 2.1 Scenario

A sensor reading below one micro-unit should count as zero.

### 2.2 Preferred form

```python
import math

reading = 0.0000004
print(math.isclose(reading, 0.0, abs_tol=0.000001))
```

### 2.3 Hazardous form

```python
import math

reading = 0.0000004
print(math.isclose(reading, 0.0))
```

### 2.4 Why this difference matters

Relative tolerance is scaled by the compared values and is ineffective when one target is zero, so the hazardous check returns `False`.

## 3. Boundaries and distinctions

Set `abs_tol` to a unit-appropriate threshold. A zero tolerance is correct only when no nonzero value should count as close.
