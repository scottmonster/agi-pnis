# Quote patterns intended for another utility

## 1. Catalog record

- **Catalog identifier:** 6.4.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Quote patterns supplied to tools such as `find`, `grep`, and `tr` when those tools, rather than Bash, should interpret them.

## 2. Example

### 2.1 Scenario

A script uses `find` to locate shell scripts below a source directory.

### 2.2 Preferred form

```bash
#!/usr/bin/env bash
find "$1" -type f -name '*.sh' -print
```

### 2.3 Hazardous form

```bash
#!/usr/bin/env bash
find "$1" -type f -name *.sh -print
```

### 2.4 Why this difference matters

Bash can expand an unquoted pattern in the current directory before `find` receives it.

## 3. Boundaries and distinctions

Leave a pattern unquoted only when Bash, not the receiving utility, is meant to interpret it.
