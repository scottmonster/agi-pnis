# Bash arithmetic is integer-only

## 1. Catalog record

- **Catalog identifier:** 7.8.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Shell arithmetic does not provide native floating-point arithmetic. Use an appropriate tool such as `awk`, `bc`, or a general-purpose language when decimal arithmetic is required.

## 2. Example

### 2.1 Scenario

A reporting script calculates the cost of several hours of work at a fractional rate. The displayed total needs decimal arithmetic.

### 2.2 Preferred form

```bash
hours=3
hourly_rate=19.95

total=$(awk -v hours="$hours" -v rate="$hourly_rate" 'BEGIN { printf "%.2f", hours * rate }')
printf 'Total: %s\n' "$total"
```

### 2.3 Hazardous form

```bash
hours=3
hourly_rate=19.95

total=$((hours * hourly_rate))
printf 'Total: %s\n' "$total"
```

### 2.4 Why this difference matters

The hazardous expression does not implement floating-point arithmetic and rejects decimal text. Delegating the calculation to a decimal-capable tool produces the intended total.

## 3. Boundaries and distinctions

Use Bash arithmetic for integral quantities such as counts and exit-status checks. For financial calculations, also choose a tool with the rounding behavior the domain requires.
