# Public API hallucination

## 1. Catalog record

- **Catalog identifier:** 2.6
- **Evidence:** e
- **Definition:** Invents a method, parameter, option, endpoint, return type, or library feature.

## 2. Scenario

### 2.1 Context

An agent adds retry handling around a third-party HTTP client already used by the project.

### 2.2 Safer approach

It consults the installed package version's types or documentation and uses the supported client configuration.

### 2.3 Failure mode

It passes `{ automaticRetry: true }`, assuming that option exists in the library.

### 2.4 Why this difference matters

The code cannot configure the library as claimed and may fail only after deployment if the option is silently ignored.

## 3. Boundaries and distinctions

This is about a nonexistent public-library feature, whereas API misuse selects a real feature but applies it incorrectly.
