# Speculative hooks/callbacks

## 1. Catalog record

- **Catalog identifier:** 3.19
- **Evidence:** se
- **Definition:** Extension points exist with zero external consumers.

## 2. Scenario

### 2.1 Context

A report generator has one internal completion action.

### 2.2 Safer approach

Perform the completion action directly in the generator.

### 2.3 Failure mode

Expose before-generate, after-generate, and error callback arrays although no consumer can register one.

### 2.4 Why this difference matters

Empty extension contracts create lifecycle promises and ordering questions with no present value.

## 3. Boundaries and distinctions

Hooks are appropriate when real external consumers need supported extension; unused hooks merely speculate about them.
