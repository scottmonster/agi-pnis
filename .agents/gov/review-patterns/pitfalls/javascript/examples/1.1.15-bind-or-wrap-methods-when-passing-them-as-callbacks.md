# Bind or wrap methods when passing them as callbacks

## 1. Catalog record

- **Catalog identifier:** 1.1.15
- **Impact:** medium
- **Consensus:** high
- **Definition:** If a method depends on `this`, do not pass the bare method reference unless the receiving API supplies the intended receiver. Bind it or use a wrapper.

## 2. Example

### 2.1 Scenario

A logger method is passed to a callback runner that invokes callbacks without a receiver.

### 2.2 Preferred form

```javascript
"use strict";

function run(callback) {
  callback("saved");
}

const logger = {
  prefix: "audit",
  write(message) {
    console.log(`${this.prefix}: ${message}`);
  },
};

run(logger.write.bind(logger));
```

### 2.3 Hazardous form

```javascript
"use strict";

function run(callback) {
  callback("saved");
}

const logger = {
  prefix: "audit",
  write(message) {
    console.log(`${this.prefix}: ${message}`);
  },
};

run(logger.write);
```

### 2.4 Why this difference matters

The callback runner does not retain `logger` as the receiver, so the bare method fails when it reads `this.prefix`.

## 3. Boundaries and distinctions

Some APIs intentionally supply a receiver. A bare method is safe only when that receiver is known to be the required object.
