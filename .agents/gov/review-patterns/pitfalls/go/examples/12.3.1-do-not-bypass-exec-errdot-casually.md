# Do not bypass `exec.ErrDot` casually

## 1. Catalog record

- **Catalog identifier:** 12.3.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** When execution from the current directory is intentional, name it explicitly with `./program` rather than weakening the protection against implicit current-directory lookup.

## 2. Example

### 2.1 Scenario

A release script intentionally runs the `report-generator` binary checked into its current working directory.

### 2.2 Preferred form

```go
package example

import "os/exec"

func generateReport() error {
	return exec.Command("./report-generator", "--format=json").Run()
}
```

### 2.3 Hazardous form

```go
package example

import (
	"errors"
	"os/exec"
)

func generateReport() error {
	cmd := exec.Command("report-generator", "--format=json")
	if errors.Is(cmd.Err, exec.ErrDot) {
		cmd.Err = nil
	}
	return cmd.Run()
}
```

### 2.4 Why this difference matters

Clearing `ErrDot` restores implicit current-directory execution, so a changed `PATH` or unexpected working directory can select a program the caller did not name.

## 3. Boundaries and distinctions

An explicit relative path is appropriate only when the current directory is intentionally part of the command contract. Prefer an absolute or otherwise trusted path when the working directory is not trusted.
