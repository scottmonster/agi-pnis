# Configure exposed HTTP servers against slow clients and large bodies

## 1. Catalog record

- **Catalog identifier:** 3.3.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Set server read/header/write/idle limits appropriate to the deployment and apply `http.MaxBytesReader` before accepting potentially large request bodies.

## 2. Example

### 2.1 Scenario

A public JSON endpoint accepts document uploads. It must prevent slow clients and oversized request bodies from consuming server resources without bound.

### 2.2 Preferred form

```go
package example

import (
	"encoding/json"
	"net/http"
	"time"
)

func upload(w http.ResponseWriter, r *http.Request) {
	r.Body = http.MaxBytesReader(w, r.Body, 1<<20)
	var document struct {
		Title string `json:"title"`
	}
	if err := json.NewDecoder(r.Body).Decode(&document); err != nil {
		http.Error(w, "invalid document", http.StatusBadRequest)
		return
	}
	w.WriteHeader(http.StatusNoContent)
}

var server = &http.Server{
	Addr:              ":8080",
	Handler:           http.HandlerFunc(upload),
	ReadHeaderTimeout: 5 * time.Second,
	ReadTimeout:       15 * time.Second,
	WriteTimeout:      15 * time.Second,
	IdleTimeout:       60 * time.Second,
}
```

### 2.3 Hazardous form

```go
package example

import (
	"encoding/json"
	"net/http"
)

func upload(w http.ResponseWriter, r *http.Request) {
	var document map[string]any
	_ = json.NewDecoder(r.Body).Decode(&document) // Body size is unbounded.
	w.WriteHeader(http.StatusNoContent)
}

var server = &http.Server{Addr: ":8080", Handler: http.HandlerFunc(upload)}
```

### 2.4 Why this difference matters

Timeouts keep slow clients from holding connections and workers indefinitely, while `MaxBytesReader` bounds memory and processing for the request body. Default server settings leave these safeguards absent.

## 3. Boundaries and distinctions

Set limits for the protocol, proxy topology, expected upload size, and legitimate slow-client needs. Streaming uploads still require an explicit size policy, although their body handling may differ from a JSON decoder.
