# Supply a numeric comparator when sorting numbers

## 1. Catalog record

- **Catalog identifier:** 3.1.7
- **Impact:** medium
- **Consensus:** high
- **Definition:** `array.sort()` without a comparator sorts values by their string representations rather than numerically. Use `(a, b) => a - b` or another intentional comparator for numeric order.

## 2. Example

### 2.1 Scenario

A dashboard sorts numeric priorities before rendering them.

### 2.2 Preferred form

```javascript
const priorities = [10, 2, 1];
priorities.sort((a, b) => a - b);

console.log(priorities); // [1, 2, 10]
```

### 2.3 Hazardous form

```javascript
const priorities = [10, 2, 1];
priorities.sort();

console.log(priorities); // [1, 10, 2]
```

### 2.4 Why this difference matters

Without a comparator, `sort` compares converted strings, placing `10` before `2` lexicographically.

## 3. Boundaries and distinctions

The default sort is appropriate when string ordering is intended. Supply a comparator for numeric or domain-specific ordering.
