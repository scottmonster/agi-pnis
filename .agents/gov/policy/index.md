# Policies

This index maps the active policy documents in this directory. Each policy defines its own scope and authority.

1. [`execution/autonomous-execution.md`](execution/autonomous-execution.md)
   Purpose: Defines the authority, decision process, risk management, documentation, and completion requirements for autonomous work.
   Relation: Directs agents to make and validate bounded decisions without routine human clarification while preserving materially relevant continuity.

2. [`preservation/preservation-strategy.md`](preservation/preservation-strategy.md)
   Purpose: Defines the context agents must discover and preserve before consequential decisions or changes.
   Relation: Covers intent, constraints, rationale, assumptions, conventions, authority, relationships, negative knowledge, intentional change, and proportionate preservation.

3. [`preservation/resolution-hierarchy.md`](preservation/resolution-hierarchy.md)
   Purpose: Defines how agents resolve incomplete, ambiguous, conflicting, or uncertain information.
   Relation: Specifies evidence authority, resolution steps, assumptions, alternatives, conflict resolution, and blocker rules.
