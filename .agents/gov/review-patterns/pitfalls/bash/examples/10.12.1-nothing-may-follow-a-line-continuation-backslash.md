# Nothing may follow a line-continuation backslash

## 1. Catalog record

- **Catalog identifier:** 10.12.1
- **Impact:** low
- **Consensus:** high
- **Definition:** A backslash continues a physical line only when it immediately precedes the newline; trailing spaces prevent continuation.

## 2. Example

### 2.1 Scenario

A script splits a `printf` command across several lines for readability.

### 2.2 Preferred form

```bash
printf '%s %s\n' \
  'ready' \
  'now'
```

### 2.3 Hazardous form

```bash
printf '%s %s\n' \
  'ready' \ 
  'now'
```

### 2.4 Why this difference matters

The space after the second backslash stops line continuation, so the final quoted word is parsed as a separate command rather than as an argument to `printf`.

## 3. Boundaries and distinctions

Use a continuation backslash only where a newline must be removed. Shell syntax that avoids continuation lines can be easier to review for invisible whitespace.
