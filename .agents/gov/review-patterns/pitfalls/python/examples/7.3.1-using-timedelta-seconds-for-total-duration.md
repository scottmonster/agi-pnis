# Using `timedelta.seconds` for total duration

## 1. Catalog record

- **Catalog identifier:** 7.3.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `timedelta.total_seconds()` when the total elapsed seconds are required rather than the `.seconds` component.

## 2. Example

### 2.1 Scenario

A job duration spans more than one day.

### 2.2 Preferred form

```python
from datetime import timedelta

duration = timedelta(days=1, seconds=30)
print(duration.total_seconds())
```

### 2.3 Hazardous form

```python
from datetime import timedelta

duration = timedelta(days=1, seconds=30)
print(duration.seconds)
```

### 2.4 Why this difference matters

`.seconds` is only the seconds component after whole days are removed, while `total_seconds()` includes every day.

## 3. Boundaries and distinctions

Use `.seconds` only when the component within the current day is intentionally required.
