# Use comma-ok when a missing map key matters

## 1. Catalog record

- **Catalog identifier:** 7.6.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `v, ok := m[k]` whenever a stored zero value must be distinguished from a missing key.

## 2. Example

### 2.1 Scenario

An inventory map allows a product to have a stored quantity of zero.

### 2.2 Preferred form

```go
package inventory

func quantity(stock map[string]int, sku string) (int, bool) {
	amount, found := stock[sku]
	return amount, found
}
```

### 2.3 Hazardous form

```go
package inventory

func available(stock map[string]int, sku string) bool {
	return stock[sku] == 0 // Missing and explicitly zero are conflated.
}
```

### 2.4 Why this difference matters

A missing SKU and a known SKU with zero stock both read as `0`, causing incorrect availability decisions.

## 3. Boundaries and distinctions

The one-result form is fine when the zero value has exactly the desired meaning for missing keys.
