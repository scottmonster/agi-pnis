# Subscripting a `super` object

## 1. Catalog record

- **Catalog identifier:** 16.15.2
- **Impact:** low
- **Consensus:** high
- **Definition:** Use explicit attribute lookup such as `super().__getitem__(key)` rather than `super()[key]`.

## 2. Example

### 2.1 Scenario

A case-insensitive mapping extends a base mapping while preserving the base lookup implementation.

### 2.2 Preferred form

```python
class HeaderMap(dict[str, str]):
    def __getitem__(self, key: str) -> str:
        return super().__getitem__(key.lower())


headers = HeaderMap({"content-type": "application/json"})
print(headers["Content-Type"])
```

### 2.3 Hazardous form

```python
class HeaderMap(dict[str, str]):
    def __getitem__(self, key: str) -> str:
        return super()[key.lower()]


headers = HeaderMap({"content-type": "application/json"})
print(headers["Content-Type"])
```

### 2.4 Why this difference matters

`super()` performs its special method-resolution behavior for explicit attribute access, not the implicit operator lookup used by `super()[key]`.

## 3. Boundaries and distinctions

Use ordinary `super().method()` calls for inherited methods. Direct access to a parent class is occasionally intentional, but it bypasses cooperative method resolution.
