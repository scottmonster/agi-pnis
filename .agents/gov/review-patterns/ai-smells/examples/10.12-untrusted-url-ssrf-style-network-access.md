# Untrusted URL/SSRF-style network access

## 1. Catalog record

- **Catalog identifier:** 10.12
- **Evidence:** e
- **Definition:** Lets untrusted input choose server-side request targets, potentially reaching internal or protected services.

## 2. Scenario

### 2.1 Context

An image-import feature fetches a URL supplied by a customer.

### 2.2 Safer approach

Restrict destinations to approved hosts or a proxy, resolve and validate addresses, and block private or link-local network ranges on every redirect.

### 2.3 Failure mode

The agent passes the submitted URL directly to the server-side HTTP client.

### 2.4 Why this difference matters

The server can be induced to query internal metadata services or protected network endpoints unavailable to the customer.

## 3. Boundaries and distinctions

Client-side URL fetching has a different network position. The risk here comes from the server’s network access and trust relationships.
