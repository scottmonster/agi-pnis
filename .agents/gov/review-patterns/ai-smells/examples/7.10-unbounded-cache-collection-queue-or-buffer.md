# Unbounded cache, collection, queue, or buffer

## 1. Catalog record

- **Catalog identifier:** 7.10
- **Evidence:** se
- **Definition:** Lets retained data grow without an eviction, size, age, or back-pressure limit.

## 2. Scenario

### 2.1 Context

An agent adds an in-memory cache for responses keyed by user search queries.

### 2.2 Safer approach

It chooses a bounded cache with eviction and a maximum size appropriate to the service's memory budget.

### 2.3 Failure mode

It stores every distinct query result forever in a process-wide map.

### 2.4 Why this difference matters

Long-running processes can consume growing memory until they slow down or fail.

## 3. Boundaries and distinctions

Some finite, lifecycle-bound collections need no separate eviction policy; this failure concerns retained data whose growth lacks an effective size, age, eviction, or back-pressure limit.
