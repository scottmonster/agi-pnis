# Understand that `types` controls globals, not imported package types

## 1. Catalog record

- **Catalog identifier:** 7.14.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `types` to control automatically included global `@types` packages, not to restrict types available through explicit imports.

## 2. Example

### 2.1 Scenario

A service wants Node globals in production code and test-runner globals in its test project, while still importing types from its SDK.

### 2.2 Preferred form

```typescript
// tsconfig.test.json
// { "compilerOptions": { "types": ["node", "vitest/globals"] } }

import type { ClientOptions } from '@acme/sdk';

describe('client configuration', () => {
  const options: ClientOptions = { retries: 2 };
  expect(options.retries).toBe(2);
});

// `types` supplies the desired ambient globals. The explicit SDK import is
// resolved through normal module resolution.
```

### 2.3 Hazardous form

```typescript
// tsconfig.json
// { "compilerOptions": { "types": [] } }

import type { ClientOptions } from '@acme/sdk';

// This import can still resolve. An empty `types` list does not prevent a
// declared dependency from contributing types when it is explicitly imported.
const options: ClientOptions = { retries: 2 };
void options;
```

### 2.4 Why this difference matters

The `types` option selects which packages under `@types` are automatically included as ambient declarations. It commonly controls globals such as `process`, `describe`, or `expect`. It does not block declarations reached by `import` or `import type`, so using it as a dependency-isolation mechanism gives a false sense of control and can leave intended globals missing.

## 3. Boundaries and distinctions

Use `types` and separate project configurations to make ambient environments intentional. Control dependency access with package boundaries, dependency management, import restrictions, or module-resolution configuration. `typeRoots` changes where automatic type packages are discovered, but explicit imports still follow normal module resolution rules.
