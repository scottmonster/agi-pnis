# Secrets or personal data written to logs

## 1. Catalog record

- **Catalog identifier:** 10.17
- **Evidence:** e
- **Definition:** Records credentials, tokens, identifiers, or sensitive payloads in logs accessible beyond the original request path.

## 2. Scenario

### 2.1 Context

An authentication callback fails intermittently in production.

### 2.2 Safer approach

Log a correlation ID, failure category, and deliberately redacted diagnostic fields, with access controls appropriate to operational logs.

### 2.3 Failure mode

The agent logs the full callback request, including the authorization header and user profile, to simplify debugging.

### 2.4 Why this difference matters

Logs are retained, aggregated, and accessed by systems and people outside the original request path, multiplying exposure.

## 3. Boundaries and distinctions

Useful audit logging is not prohibited. The distinction is whether each field is necessary, protected, and safely redacted for the operational audience.
