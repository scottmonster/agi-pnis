# Scope creep

## 1. Catalog record

- **Catalog identifier:** 1.5
- **Evidence:** a/se
- **Definition:** Fixes unrelated bugs, performs opportunistic cleanup, or implements adjacent features in the same change.

## 2. Scenario

### 2.1 Context

A task requests changing the invoice email subject. The relevant template is in a stable notification module.

### 2.2 Safer approach

Update the subject in the template, adjust the focused test if needed, and leave unrelated notification behavior unchanged.

### 2.3 Failure mode

Alongside the subject change, the agent rewrites all email templates, upgrades a mail library, and fixes an unrelated attachment issue.

### 2.4 Why this difference matters

Reviewers must now evaluate several independent risks, and regressions from unrelated work can delay a simple requested change.

## 3. Boundaries and distinctions

Related changes are appropriate when they are required for the requested behavior to work or remain compatible. This failure concerns work with no such dependency.
