# Tautological test

## 1. Catalog record

- **Catalog identifier:** 9.4
- **Evidence:** se
- **Definition:** Reimplements the production algorithm and compares it with itself.

## 2. Scenario

### 2.1 Context

A function classifies a score as passing when it is at least 70.

### 2.2 Safer approach

Assert known contract examples at 69, 70, and 71 without copying the decision logic.

### 2.3 Failure mode

Use a test helper with the same `score >= 70` condition, then compare its answer with the production result.

### 2.4 Why this difference matters

The same defect can be introduced in both copies and make the test confirm the wrong behavior.

## 3. Boundaries and distinctions

Independent reference implementations can be useful for complex algorithms when genuinely separate and validated, not when they duplicate the same logic casually.
