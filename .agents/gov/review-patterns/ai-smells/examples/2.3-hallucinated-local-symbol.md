# Hallucinated local symbol

## 1. Catalog record

- **Catalog identifier:** 2.3
- **Evidence:** e
- **Definition:** Invents a function, class, module, field, constant, command, or variable that does not exist.

## 2. Scenario

### 2.1 Context

An agent needs to format an order total in a TypeScript service.

### 2.2 Safer approach

It searches local utilities and imports the existing `formatCurrency` helper after confirming its signature.

### 2.3 Failure mode

It writes `formatOrderMoney(total)` based on a plausible name, even though no such helper exists.

### 2.4 Why this difference matters

The change fails to compile or leaves a nonexistent dependency for a later developer to resolve.

## 3. Boundaries and distinctions

Adding a new symbol can be valid when the task calls for it; the failure is presenting an invented symbol as existing project functionality.
