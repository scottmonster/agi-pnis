# Failing to read actual error output

## 1. Catalog record

- **Catalog identifier:** 13.7
- **Evidence:** a
- **Definition:** Ignores the diagnostic details that identify the failed command, location, cause, or next investigation step.

## 2. Scenario

### 2.1 Context

A type-check command fails and reports an incompatible value at a specific source line.

### 2.2 Safer approach

The agent reads the full diagnostic, opens that line and the declared type, and corrects the value or conversion.

### 2.3 Failure mode

The agent sees only that the command exited nonzero and changes an unrelated import based on a guess.

### 2.4 Why this difference matters

The diagnostic already narrows the problem. Ignoring it turns a targeted fix into speculation.

## 3. Boundaries and distinctions

Error text may be incomplete or misleading, but it should be examined and combined with repository evidence before choosing the next step.
