# Feature-isolation overfitting

## 1. Catalog record

- **Catalog identifier:** 9.15
- **Evidence:** a
- **Definition:** Individual features work in tests but fail when composed together.

## 2. Scenario

### 2.1 Context

A reporting endpoint supports date filters, pagination, and CSV export.

### 2.2 Safer approach

Test each feature and an export request that combines filtering with a later pagination page.

### 2.3 Failure mode

Test date filtering, pagination, and export only in separate requests.

### 2.4 Why this difference matters

The combined path can apply pagination before filtering and export the wrong records despite every isolated test passing.

## 3. Boundaries and distinctions

Prioritize combinations that users actually need or whose interactions share state, transformations, or ordering rules.
