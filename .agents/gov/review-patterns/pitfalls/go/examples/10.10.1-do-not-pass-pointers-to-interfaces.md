# Do not pass pointers to interfaces

## 1. Catalog record

- **Catalog identifier:** 10.10.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Accept or return the interface value itself rather than `*SomeInterface` except for rare cases where the interface variable itself must be mutated.

## 2. Example

### 2.1 Scenario

A formatter writes a status line to any destination that implements `io.Writer`.

### 2.2 Preferred form

```go
package example

import (
	"fmt"
	"io"
)

func writeStatus(dst io.Writer, status string) error {
	_, err := fmt.Fprintln(dst, status)
	return err
}
```

### 2.3 Hazardous form

```go
package example

import (
	"fmt"
	"io"
)

func writeStatus(dst *io.Writer, status string) error {
	_, err := fmt.Fprintln(*dst, status)
	return err
}
```

### 2.4 Why this difference matters

An interface value already contains a dynamic value and method set. A pointer adds indirection, requires callers to create an interface variable first, and obscures whether the function needs to replace that variable.

## 3. Boundaries and distinctions

Use `*interface` only when the function intentionally mutates which concrete value an interface variable holds. It is not needed merely to avoid copying the interface value.
