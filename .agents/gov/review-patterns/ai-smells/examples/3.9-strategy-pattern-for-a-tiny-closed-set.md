# Strategy pattern for a tiny closed set

## 1. Catalog record

- **Catalog identifier:** 3.9
- **Evidence:** se
- **Definition:** Multiple strategy classes encode two simple algorithms unlikely to vary independently.

## 2. Scenario

### 2.1 Context

Shipping cost has a domestic formula and an international formula.

### 2.2 Safer approach

Keep the two formulas in a small conditional with focused tests.

### 2.3 Failure mode

Create a strategy interface and separate class hierarchy for the two one-line calculations.

### 2.4 Why this difference matters

Class ceremony makes a closed rule set harder to follow and modify together.

## 3. Boundaries and distinctions

Strategies are appropriate when algorithms vary independently or are selected by real external extension; a tiny fixed set may be clearer inline.
