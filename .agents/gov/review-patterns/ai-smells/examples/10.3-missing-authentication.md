# Missing authentication

## 1. Catalog record

- **Catalog identifier:** 10.3
- **Evidence:** e
- **Definition:** Permits use of a protected function or resource without establishing the caller’s identity.

## 2. Scenario

### 2.1 Context

An internal endpoint returns account invoices.

### 2.2 Safer approach

Require and validate the service’s session or bearer token before the handler reads account data.

### 2.3 Failure mode

The agent implements the endpoint and assumes network placement makes the caller trustworthy, so it adds no identity check.

### 2.4 Why this difference matters

Any reachable caller can invoke a resource intended only for known users or services.

## 3. Boundaries and distinctions

Public endpoints can intentionally allow anonymous use. Authentication establishes identity; it does not decide whether that identity may perform a particular action.
