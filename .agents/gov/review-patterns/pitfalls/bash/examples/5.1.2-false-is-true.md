# `[ false ]` is true

## 1. Catalog record

- **Catalog identifier:** 5.1.2
- **Impact:** medium
- **Consensus:** high
- **Definition:** A one-argument `test` is true when its argument is a nonempty string. Therefore `[ false ]`, `[ 0 ]`, and similar constructs are true. Run commands such as `false` directly or perform an explicit comparison.

## 2. Example

### 2.1 Scenario

A script reads a textual feature flag whose accepted values are the literal strings `true` and `false`.

### 2.2 Preferred form

```bash
feature_enabled=${1:-false}

if [[ $feature_enabled == true ]]; then
  printf 'feature enabled\n'
else
  printf 'feature disabled\n'
fi
```

### 2.3 Hazardous form

```bash
feature_enabled=${1:-false}

if [ "$feature_enabled" ]; then
  printf 'feature enabled\n'
else
  printf 'feature disabled\n'
fi
```

### 2.4 Why this difference matters

`[` treats its single nonempty argument as a true expression. The hazardous form therefore enables the feature for the value `false` instead of interpreting it as a boolean.

## 3. Boundaries and distinctions

Testing whether a string is nonempty with `[ -n "$value" ]` is valid. Use an explicit comparison when a particular textual value has boolean meaning.
