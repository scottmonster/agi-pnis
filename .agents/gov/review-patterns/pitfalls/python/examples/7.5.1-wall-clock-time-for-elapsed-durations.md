# Wall-clock time for elapsed durations

## 1. Catalog record

- **Catalog identifier:** 7.5.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Measure elapsed time and deadlines using `time.monotonic()` or `time.perf_counter()` rather than subtracting `time.time()` values.

## 2. Example

### 2.1 Scenario

A timeout measures how long an operation takes.

### 2.2 Preferred form

```python
import time

started = time.monotonic()
# Perform the operation here.
elapsed = time.monotonic() - started
print(elapsed)
```

### 2.3 Hazardous form

```python
import time

started = time.time()
# Perform the operation here.
elapsed = time.time() - started
print(elapsed)
```

### 2.4 Why this difference matters

Wall-clock time can jump because of clock synchronization or manual changes, causing an elapsed duration to be negative or inaccurate.

## 3. Boundaries and distinctions

Use wall-clock time when recording a real-world timestamp. Use a monotonic clock for durations, intervals, and deadlines.
