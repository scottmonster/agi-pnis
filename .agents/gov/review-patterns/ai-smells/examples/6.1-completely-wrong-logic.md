# Completely wrong logic

## 1. Catalog record

- **Catalog identifier:** 6.1
- **Evidence:** e
- **Definition:** The implementation computes or changes the wrong result for the intended task rather than merely mishandling an edge case.

## 2. Scenario

### 2.1 Context

A billing service must apply a percentage discount to an order subtotal.

### 2.2 Safer approach

The agent traces the stated formula, adds a representative example, and calculates `subtotal * (1 - discount_rate)`.

### 2.3 Failure mode

It implements `subtotal * discount_rate`, returning the discount amount as though it were the final price.

### 2.4 Why this difference matters

Every normal order receives the wrong total, not merely a difficult input case.

## 3. Boundaries and distinctions

This concerns an incorrect core result; a correct formula that fails only at a boundary is a missing edge or corner case.
