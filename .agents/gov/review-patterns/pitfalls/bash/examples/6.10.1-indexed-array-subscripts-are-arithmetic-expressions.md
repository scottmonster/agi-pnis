# Indexed-array subscripts are arithmetic expressions

## 1. Catalog record

- **Catalog identifier:** 6.10.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** `array[index]` does not require `index` to be a simple decimal literal. Indexed-array subscripts are evaluated arithmetically. Validate externally supplied index values rather than assuming they are inert strings.

## 2. Example

### 2.1 Scenario

A command accepts a user-provided deployment-environment index.

### 2.2 Preferred form

```bash
#!/usr/bin/env bash
index=$1
environments=(development staging production)
if [[ ! $index =~ ^[0-9]+$ ]] || (( index >= ${#environments[@]} )); then exit 1; fi
echo "${environments[index]}"
```

### 2.3 Hazardous form

```bash
#!/usr/bin/env bash
index=$1
environments=(development staging production)
echo "${environments[index]}"
```

### 2.4 Why this difference matters

Subscripts are arithmetic expressions, so unvalidated input can calculate unexpected indexes or cause arithmetic side effects.

## 3. Boundaries and distinctions

Arithmetic expressions are useful for internal indexes. Validate external values when a simple decimal position is the intended interface.
