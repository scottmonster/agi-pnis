# Cross-site scripting / unsafe HTML rendering

## 1. Catalog record

- **Catalog identifier:** 10.9
- **Evidence:** e
- **Definition:** Renders untrusted content as active HTML or script in a user’s browser.

## 2. Scenario

### 2.1 Context

A project displays comments submitted by other users.

### 2.2 Safer approach

Render comment text through the framework’s escaped text binding, or sanitize it with a maintained policy if limited markup is a requirement.

### 2.3 Failure mode

The agent inserts the comment into an HTML template as trusted markup to preserve formatting.

### 2.4 Why this difference matters

Malicious content can execute in another user’s browser and act with that user’s session or trust.

## 3. Boundaries and distinctions

Trusted, reviewed static markup is not the same as user input. Escaping and sanitizing serve different needs when rich text is explicitly supported.
