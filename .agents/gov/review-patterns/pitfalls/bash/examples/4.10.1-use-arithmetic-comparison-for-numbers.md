# Use arithmetic comparison for numbers

## 1. Catalog record

- **Catalog identifier:** 4.10.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use arithmetic or numeric operators when comparing numbers, not lexicographic string ordering.

## 2. Example

### 2.1 Scenario

A retry policy must report when the retry count exceeds seven.

### 2.2 Preferred form

```bash
#!/usr/bin/env bash

retries=${1:-12}
if (( retries > 7 )); then
  printf 'retry limit exceeded\n'
fi
```

### 2.3 Hazardous form

```bash
#!/usr/bin/env bash

retries=${1:-12}
if [[ $retries > 7 ]]; then
  printf 'retry limit exceeded\n'
fi
```

### 2.4 Why this difference matters

The `>` operator in `[[ ... ]]` compares strings lexicographically. For example, `12` sorts before `7`, so the hazardous condition produces the wrong result.

## 3. Boundaries and distinctions

Use arithmetic syntax or numeric test operators for values that are numbers. Validate externally supplied values first if nonnumeric input is possible.
