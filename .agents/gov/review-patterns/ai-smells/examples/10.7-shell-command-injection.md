# Shell/command injection

## 1. Catalog record

- **Catalog identifier:** 10.7
- **Evidence:** e
- **Definition:** Incorporates untrusted data into an operating-system command so an attacker can execute unintended arguments or commands.

## 2. Scenario

### 2.1 Context

A maintenance endpoint generates a report for a user-selected file.

### 2.2 Safer approach

Avoid the shell, pass a fixed executable and separately validated arguments, and constrain the file to an approved directory.

### 2.3 Failure mode

The agent interpolates the request value into a shell command string and executes it.

### 2.4 Why this difference matters

Shell syntax in the input can introduce extra arguments or commands with the service’s privileges.

## 3. Boundaries and distinctions

Argument arrays reduce shell interpretation but do not by themselves make unsafe file paths or application-level arguments safe.
