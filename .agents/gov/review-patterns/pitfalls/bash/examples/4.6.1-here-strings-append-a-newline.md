# Here strings append a newline

## 1. Catalog record

- **Catalog identifier:** 4.6.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use another input mechanism when exact stream contents are required because here strings add a newline.

## 2. Example

### 2.1 Scenario

A checksum helper must receive exactly the characters held in a shell variable.

### 2.2 Preferred form

```bash
#!/usr/bin/env bash

checksum_from_stdin() {
  wc -c
}

payload='token-without-a-final-newline'
printf '%s' "$payload" | checksum_from_stdin
```

### 2.3 Hazardous form

```bash
#!/usr/bin/env bash

checksum_from_stdin() {
  wc -c
}

payload='token-without-a-final-newline'
checksum_from_stdin <<< "$payload"
```

### 2.4 Why this difference matters

A here string supplies the expanded value followed by a newline. That extra byte changes a digest, signature input, or other exact stream protocol.

## 3. Boundaries and distinctions

Here strings are concise for line-oriented input where an ending newline is wanted. Use `printf '%s'` or a file descriptor when stream contents must be exact.
