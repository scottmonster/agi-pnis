# Remember that typeof null is "object"

## 1. Catalog record

- **Catalog identifier:** 1.1.8
- **Impact:** medium
- **Consensus:** high
- **Definition:** Do not use `typeof x === "object"` alone when `null` must be excluded. Add an explicit null check.

## 2. Example

### 2.1 Scenario

A settings reader accepts only a configuration object.

### 2.2 Preferred form

```javascript
function isConfiguration(value) {
  return value !== null && typeof value === "object";
}

console.log(isConfiguration(null));
```

### 2.3 Hazardous form

```javascript
function isConfiguration(value) {
  return typeof value === "object";
}

console.log(isConfiguration(null));
```

### 2.4 Why this difference matters

The historical `typeof null` result is `"object"`, so the hazardous check accepts a value that cannot provide configuration properties.

## 3. Boundaries and distinctions

This check identifies non-null objects broadly. Arrays, dates, and other object kinds may need additional validation.
