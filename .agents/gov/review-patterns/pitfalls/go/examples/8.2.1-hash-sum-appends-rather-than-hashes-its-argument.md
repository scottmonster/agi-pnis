# `Hash.Sum` appends rather than hashes its argument

## 1. Catalog record

- **Catalog identifier:** 8.2.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** After writing input into a `hash.Hash`, use `h.Sum(nil)` or append the digest intentionally. Do not pass source data to `Sum` expecting it to be hashed.

## 2. Example

### 2.1 Scenario

A service computes a SHA-256 digest for a received payload before storing the digest alongside the payload.

### 2.2 Preferred form

```go
package digest

import (
	"crypto/sha256"
	"hash"
)

func checksum(payload []byte) []byte {
	var h hash.Hash = sha256.New()
	h.Write(payload)
	return h.Sum(nil)
}
```

### 2.3 Hazardous form

```go
package digest

import (
	"crypto/sha256"
	"hash"
)

func checksum(payload []byte) []byte {
	var h hash.Hash = sha256.New()
	return h.Sum(payload)
}
```

### 2.4 Why this difference matters

`Sum` appends the current digest to its argument. The hazardous code returns the original payload followed by the digest of an empty input, rather than the digest of the payload.

## 3. Boundaries and distinctions

Passing a non-nil slice to `Sum` is appropriate when deliberately appending a digest to an existing buffer. Input must be supplied through `Write` or a helper such as `io.Copy`.
