# Configure private module paths before fetching them

## 1. Catalog record

- **Catalog identifier:** 4.8.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Configure `GOPRIVATE` and, where needed, `GONOPROXY` or `GONOSUMDB` for private module path patterns.

## 2. Example

### 2.1 Scenario

A build job downloads a module hosted on the organization's private Git service.

### 2.2 Preferred form

```go
package example

import (
	"context"
	"os"
	"os/exec"
)

func downloadPrivateModule(ctx context.Context) error {
	cmd := exec.CommandContext(ctx, "go", "mod", "download", "git.example.com/acme/payments")
	cmd.Env = append(os.Environ(),
		"GOPRIVATE=git.example.com/acme/*",
		"GONOPROXY=git.example.com/acme/*",
		"GONOSUMDB=git.example.com/acme/*",
	)
	return cmd.Run()
}
```

### 2.3 Hazardous form

```go
package example

import (
	"context"
	"os/exec"
)

func downloadPrivateModule(ctx context.Context) error {
	return exec.CommandContext(ctx, "go", "mod", "download", "git.example.com/acme/payments").Run()
}
```

### 2.4 Why this difference matters

Private paths need configuration before the Go command resolves them, so the command does not disclose the path to a public proxy or checksum database. The hazardous form depends on ambient configuration and can contact services that cannot access the private module.

## 3. Boundaries and distinctions

Set these variables in the developer or build environment when that is clearer than setting a command-specific environment. Use the narrowest path pattern that covers the private modules, and do not use private-module settings for public dependencies.
