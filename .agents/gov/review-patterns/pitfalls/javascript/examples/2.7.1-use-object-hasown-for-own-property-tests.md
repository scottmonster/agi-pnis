# Use Object.hasOwn for own-property tests

## 1. Catalog record

- **Catalog identifier:** 2.7.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `Object.hasOwn()` when inherited properties must be excluded.

## 2. Example

### 2.1 Scenario

A request parser must accept only fields supplied by the caller.

### 2.2 Preferred form

```javascript
const request = Object.create({ role: "admin" });
request.name = "Ari";

console.log(Object.hasOwn(request, "role"));
```

### 2.3 Hazardous form

```javascript
const request = Object.create({ role: "admin" });
request.name = "Ari";

console.log("role" in request);
```

### 2.4 Why this difference matters

The `in` operator includes inherited properties, so the hazardous check treats a prototype value as caller input.

## 3. Boundaries and distinctions

Use `in` when inherited properties are intentionally part of the lookup. `Object.hasOwn()` also works for null-prototype objects.
