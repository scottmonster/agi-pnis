# Debug prints/logging left behind

## 1. Catalog record

- **Catalog identifier:** 11.15
- **Evidence:** se
- **Definition:** Leaves temporary diagnostic output that adds noise, leaks data, or changes operational behavior.

## 2. Scenario

### 2.1 Context

An agent investigates why a payment webhook is rejected in staging.

### 2.2 Safer approach

The agent uses temporary redacted diagnostics locally, resolves the signature issue, and removes diagnostics before delivery.

### 2.3 Failure mode

The final patch prints the complete webhook headers and payload on every request.

### 2.4 Why this difference matters

Production logs become noisy and may expose customer data or security-sensitive values.

## 3. Boundaries and distinctions

Retained logs can be valuable when they are operationally meaningful, appropriately leveled, and redacted; temporary raw diagnostics are not.
