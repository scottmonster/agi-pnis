# Weak assertions

## 1. Catalog record

- **Catalog identifier:** 9.3
- **Evidence:** a
- **Definition:** Test executes code but does not meaningfully verify the result.

## 2. Scenario

### 2.1 Context

A tax calculator must apply a regional rate and return a monetary total.

### 2.2 Safer approach

Assert the exact total for representative inputs and the specified rounding behavior.

### 2.3 Failure mode

Call the calculator and assert only that the returned value is not null.

### 2.4 Why this difference matters

The test passes for a wrong rate, a zero result, or incorrect rounding, so it supplies little regression protection.

## 3. Boundaries and distinctions

An assertion need not expose implementation details, but it must establish a meaningful contract outcome.
