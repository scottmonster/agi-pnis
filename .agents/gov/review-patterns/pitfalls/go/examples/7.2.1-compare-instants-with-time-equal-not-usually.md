# Compare instants with `Time.Equal`, not usually `==`

## 1. Catalog record

- **Catalog identifier:** 7.2.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `t.Equal(u)` for instant equality. Normalize deliberately before using `time.Time` as a map or database key.

## 2. Example

### 2.1 Scenario

An API compares a timestamp parsed from RFC 3339 with the same moment in a local time zone.

### 2.2 Preferred form

```go
package schedule

import "time"

func sameInstant(a, b time.Time) bool { return a.Equal(b) }
```

### 2.3 Hazardous form

```go
package schedule

import "time"

func sameInstant(a, b time.Time) bool { return a == b }
```

### 2.4 Why this difference matters

`==` also compares representation details such as location and monotonic-clock data, so it can report unequal values for the same instant.

## 3. Boundaries and distinctions

Use `==` deliberately when representation-level equality is the actual contract, such as for a normalized map key.
