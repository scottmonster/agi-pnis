# Stopping a ticker does not close its channel

## 1. Catalog record

- **Catalog identifier:** 6.15.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Do not expect `range ticker.C` to terminate merely because another goroutine calls `ticker.Stop()`. Provide a separate cancellation signal.

## 2. Example

### 2.1 Scenario

A periodic refresher exits on context cancellation.

### 2.2 Preferred form

```go
package main

import (
	"context"
	"time"
)

func refresh(ctx context.Context) {
	ticker := time.NewTicker(time.Minute)
	defer ticker.Stop()
	for {
		select {
		case <-ctx.Done():
			return
		case <-ticker.C:
			refreshCache()
		}
	}
}

func refreshCache() {}
```

### 2.3 Hazardous form

```go
package main

import "time"

func refresh(ticker *time.Ticker) {
	for range ticker.C {
		refreshCache()
	}
}

func refreshCache() {}

func stop(ticker *time.Ticker) { ticker.Stop() }
```

### 2.4 Why this difference matters

`Stop` halts ticks but does not close `ticker.C`, leaving the range blocked. Cancellation provides the termination signal.

## 3. Boundaries and distinctions

A done channel works when context is unsuitable. Stop the ticker and terminate the goroutine independently.
