# Missing validation/precondition

## 1. Catalog record

- **Catalog identifier:** 6.14
- **Evidence:** e
- **Definition:** Calls APIs or operates on values without checking conditions necessary for correctness.

## 2. Scenario

### 2.1 Context

A resize operation requires a positive integer width.

### 2.2 Safer approach

The agent validates the width before invoking the image library and returns a useful request error.

### 2.3 Failure mode

It passes an unchecked width directly to the resize call.

### 2.4 Why this difference matters

Invalid input can trigger an opaque library failure or produce an unusable result.

## 3. Boundaries and distinctions

Only conditions necessary for correctness belong here; unnecessary validation can add unrequested behavior or duplicate an enforced boundary.
