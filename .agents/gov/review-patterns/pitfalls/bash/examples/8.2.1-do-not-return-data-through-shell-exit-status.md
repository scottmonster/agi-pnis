# Do not return data through shell exit status

## 1. Catalog record

- **Catalog identifier:** 8.2.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Shell command and function status is a small numeric success or failure channel, so return substantive data through stdout, variables, arrays, or another explicit interface.

## 2. Example

### 2.1 Scenario

A function calculates a record count for a caller that must handle values above 255.

### 2.2 Preferred form

```bash
count_records() {
  printf '%s\n' 300
}

record_count=$(count_records) || exit 1
printf 'processed %s records\n' "$record_count"
```

### 2.3 Hazardous form

```bash
count_records() {
  return 300
}

count_records
record_count=$?
printf 'processed %s records\n' "$record_count"
```

### 2.4 Why this difference matters

Exit status is conventionally limited to 0 through 255, so returning 300 is truncated and does not preserve the data. The status should instead indicate whether producing output succeeded.

## 3. Boundaries and distinctions

Use an exit status for a small success or failure result. Use stdout only when it is the function's documented data channel and callers can capture it safely.
