# `deque.extendleft()` reversing input order

## 1. Catalog record

- **Catalog identifier:** 8.12.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Account for reversal when using `extendleft()`, or reverse the input first when preserving its order is required.

## 2. Example

### 2.1 Scenario

A queue prepends urgent tasks while preserving the tasks' existing order.

### 2.2 Preferred form

```python
from collections import deque

queue = deque(["normal"])
urgent = ["first", "second"]
queue.extendleft(reversed(urgent))

assert list(queue) == ["first", "second", "normal"]
```

### 2.3 Hazardous form

```python
from collections import deque

queue = deque(["normal"])
queue.extendleft(["first", "second"])

assert list(queue) == ["second", "first", "normal"]
```

### 2.4 Why this difference matters

`extendleft()` repeatedly appends each input item to the left, reversing the observed input order.

## 3. Boundaries and distinctions

The direct form is appropriate when reversal is desired or the input has only one item.
