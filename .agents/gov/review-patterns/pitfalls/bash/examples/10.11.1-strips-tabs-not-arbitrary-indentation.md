# `<<-` strips tabs, not arbitrary indentation

## 1. Catalog record

- **Catalog identifier:** 10.11.1
- **Impact:** low
- **Consensus:** high
- **Definition:** The `<<-` here-document form removes leading tab characters from its body and delimiter, not general space indentation.

## 2. Example

### 2.1 Scenario

A script indents a here-document in a function while generating a short configuration file.

### 2.2 Preferred form

```bash
render_config() {
	cat <<-EOF
	name=example
	EOF
}

render_config
```

### 2.3 Hazardous form

```bash
render_config() {
  cat <<-EOF
  name=example
  EOF
EOF
}

render_config
```

### 2.4 Why this difference matters

The spaces before the first `EOF` are content, not indentation to strip, so the delimiter is not recognized until the later unindented line.

## 3. Boundaries and distinctions

Use `<<-` when literal tabs are acceptable for source indentation. If spaces must indent the body, place the delimiter at column zero or choose another construction.
