# Remove temporary files you create

## 1. Catalog record

- **Catalog identifier:** 8.1.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** `os.CreateTemp` and `os.MkdirTemp` create resources but do not automatically remove them when the process no longer needs them.

## 2. Example

### 2.1 Scenario

A report generator needs a temporary file while it renders a response, then has no further use for that file.

### 2.2 Preferred form

```go
package report

import "os"

func render() error {
	f, err := os.CreateTemp("", "report-*")
	if err != nil {
		return err
	}
	defer os.Remove(f.Name())
	defer f.Close()

	_, err = f.WriteString("report")
	return err
}
```

### 2.3 Hazardous form

```go
package report

import "os"

func render() error {
	f, err := os.CreateTemp("", "report-*")
	if err != nil {
		return err
	}
	defer f.Close()

	_, err = f.WriteString("report")
	return err
}
```

### 2.4 Why this difference matters

Closing the file releases its descriptor but leaves the pathname and disk space behind. Repeated requests can accumulate temporary files until storage or cleanup tooling fails.

## 3. Boundaries and distinctions

Do not remove a temporary resource before a caller or another process has finished using it. For a temporary directory, defer `os.RemoveAll` only when its entire contents are owned by this operation.
