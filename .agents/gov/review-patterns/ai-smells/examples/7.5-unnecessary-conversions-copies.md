# Unnecessary conversions/copies

## 1. Catalog record

- **Catalog identifier:** 7.5
- **Evidence:** e
- **Definition:** Repeatedly transforms or duplicates data when the original representation or a single conversion would suffice.

## 2. Scenario

### 2.1 Context

An agent updates a pipeline that validates and forwards JSON request data.

### 2.2 Safer approach

It keeps the parsed object through validation and serializes it once at the boundary that needs bytes.

### 2.3 Failure mode

It serializes and reparses the same payload between each helper, creating copies at every step.

### 2.4 Why this difference matters

The pipeline does extra allocation and CPU work without gaining a needed representation.

## 3. Boundaries and distinctions

Conversions remain necessary at API, storage, ownership, or isolation boundaries; the failure is needless repetition when the existing representation would work.
