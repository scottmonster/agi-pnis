# Quote array subscripts passed to `unset`

## 1. Catalog record

- **Catalog identifier:** 7.4.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Use `unset 'array[index]'` or another safely quoted form rather than leaving brackets exposed to filename expansion.

## 2. Example

### 2.1 Scenario

A script removes the completed item from an in-memory work queue. It may run in a directory containing arbitrary filenames.

### 2.2 Preferred form

```bash
queue=(download verify publish)

unset 'queue[1]'
printf '%s\n' "${queue[@]}"
```

### 2.3 Hazardous form

```bash
work_dir=$(mktemp -d)
cd "$work_dir" || exit 1
touch queue1

queue=(download verify publish)
unset queue[1]
printf '%s\n' "${queue[@]}"
```

### 2.4 Why this difference matters

In the hazardous form, `queue[1]` can match the filename `queue1` before `unset` receives it. The intended array element remains assigned because the shell passed a different argument to the builtin.

## 3. Boundaries and distinctions

An arithmetic-aware assignment context has different parsing rules, but `unset` arguments are ordinary shell words. Quote bracketed array references whenever pathname expansion could apply.
