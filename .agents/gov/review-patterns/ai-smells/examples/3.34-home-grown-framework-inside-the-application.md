# Home-grown framework inside the application

## 1. Catalog record

- **Catalog identifier:** 3.34
- **Evidence:** se
- **Definition:** Builds routers, validators, event systems, ORM-like layers, or component frameworks already provided by the platform.

## 2. Scenario

### 2.1 Context

The selected web framework already supplies routing, request validation, and database integration.

### 2.2 Safer approach

Use the platform facilities and add application code only for domain-specific behavior.

### 2.3 Failure mode

Build custom routing, validation, and data-mapping frameworks inside the application for capabilities already available.

### 2.4 Why this difference matters

The application inherits a duplicate platform to test, secure, document, and maintain.

## 3. Boundaries and distinctions

Custom infrastructure can be justified by a documented platform limitation; recreating available facilities without that need is the failure.
