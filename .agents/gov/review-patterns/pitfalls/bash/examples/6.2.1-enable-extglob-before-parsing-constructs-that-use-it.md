# Enable `extglob` before parsing constructs that use it

## 1. Catalog record

- **Catalog identifier:** 6.2.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Extended glob syntax can affect parsing. Enable `extglob` before Bash parses function bodies or compound commands containing that syntax.

## 2. Example

### 2.1 Scenario

A function deletes generated files except retained configuration.

### 2.2 Preferred form

```bash
#!/usr/bin/env bash
shopt -s extglob
remove_generated() { rm -f -- "$1"/!(config.ini|keep.txt); }
remove_generated "$1"
```

### 2.3 Hazardous form

```bash
#!/usr/bin/env bash
remove_generated() { shopt -s extglob; rm -f -- "$1"/!(config.ini|keep.txt); }
remove_generated "$1"
```

### 2.4 Why this difference matters

Bash parses the function before it executes its body, so enabling the option inside it can be too late.

## 3. Boundaries and distinctions

Enable the option before any compound command that contains extended glob syntax.
