# Copy borrowed buffers before retaining them

## 1. Catalog record

- **Catalog identifier:** 7.18.1
- **Impact:** medium
- **Consensus:** high
- **Definition:** Data returned by APIs such as `Scanner.Bytes`, `bufio.Reader.Peek`, `ReadSlice`, or `bytes.Buffer.Bytes` may alias internal mutable storage. Copy it if it must survive subsequent reads or mutations.

## 2. Example

### 2.1 Scenario

A line reader keeps the first scanned line after continuing to scan more input.

### 2.2 Preferred form

```go
package lines

import "bufio"

func first(scanner *bufio.Scanner) []byte {
	if !scanner.Scan() { return nil }
	line := append([]byte(nil), scanner.Bytes()...)
	scanner.Scan() // The copy remains valid after another scan.
	return line
}
```

### 2.3 Hazardous form

```go
package lines

import "bufio"

func first(scanner *bufio.Scanner) []byte {
	if !scanner.Scan() { return nil }
	line := scanner.Bytes()
	scanner.Scan() // Can overwrite line's borrowed storage.
	return line
}
```

### 2.4 Why this difference matters

The scanner owns the returned memory and may reuse it, so retained data can silently change after later reads.

## 3. Boundaries and distinctions

Do not copy when the bytes are consumed before the next operation that can invalidate the borrowed buffer.
