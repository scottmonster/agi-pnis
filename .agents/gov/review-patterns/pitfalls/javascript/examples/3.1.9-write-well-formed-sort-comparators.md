# Write well-formed sort comparators

## 1. Catalog record

- **Catalog identifier:** 3.1.9
- **Impact:** medium
- **Consensus:** high
- **Definition:** Comparators should obey consistent ordering rules including anti-symmetry and transitivity. Do not return only `0` and `1` for a normal ascending comparison.

## 2. Example

### 2.1 Scenario

A service sorts scores into a stable ascending ranking.

### 2.2 Preferred form

```javascript
const scores = [3, 1, 2];
scores.sort((left, right) => left - right);

console.log(scores); // [1, 2, 3]
```

### 2.3 Hazardous form

```javascript
const scores = [3, 1, 2];
scores.sort((left, right) => (left > right ? 1 : 0));

console.log(scores);
```

### 2.4 Why this difference matters

The hazardous comparator never reports that the left value should precede the right one, violating comparator ordering requirements and allowing inconsistent results.

## 3. Boundaries and distinctions

A comparator may use any negative, zero, or positive values, but it must give a consistent ordering for the values it compares.
