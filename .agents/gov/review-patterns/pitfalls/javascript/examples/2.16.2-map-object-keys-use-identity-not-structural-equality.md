# Map object keys use identity, not structural equality

## 1. Catalog record

- **Catalog identifier:** 2.16.2
- **Impact:** medium
- **Consensus:** high
- **Definition:** Treat object Map keys as identity keys and implement structural matching separately when needed.

## 2. Example

### 2.1 Scenario

A registry stores a handler for a particular connection object.

### 2.2 Preferred form

```javascript
const connection = { host: "db.local" };
const handlers = new Map([[connection, "primary"]]);

console.log(handlers.get(connection));
```

### 2.3 Hazardous form

```javascript
const handlers = new Map([[{ host: "db.local" }, "primary"]]);

console.log(handlers.get({ host: "db.local" }));
```

### 2.4 Why this difference matters

The two object literals have matching contents but different identities, so the hazardous lookup returns `undefined`.

## 3. Boundaries and distinctions

Use a stable primitive key or a purpose-built structural comparison when matching by object content is required.
