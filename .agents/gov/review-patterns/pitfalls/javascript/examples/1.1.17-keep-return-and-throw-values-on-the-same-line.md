# Keep return and throw values on the same line

## 1. Catalog record

- **Catalog identifier:** 1.1.17
- **Impact:** high
- **Consensus:** high
- **Definition:** Write the expression for `return` or `throw` on the same line as the keyword. A newline immediately after `return` triggers automatic semicolon insertion, and a newline after `throw` is invalid.

## 2. Example

### 2.1 Scenario

A request helper returns an object that describes a successful result.

### 2.2 Preferred form

```javascript
function createResult() {
  return {
    status: "ok",
  };
}

console.log(createResult());
```

### 2.3 Hazardous form

```javascript
function createResult() {
  return
  {
    status: "ok",
  };
}

console.log(createResult());
```

### 2.4 Why this difference matters

Automatic semicolon insertion ends the `return` statement before the object literal, so the function returns `undefined`.

## 3. Boundaries and distinctions

Line breaks inside a returned expression are fine when the expression starts on the same line as `return`. A newline after `throw` is a syntax error.
