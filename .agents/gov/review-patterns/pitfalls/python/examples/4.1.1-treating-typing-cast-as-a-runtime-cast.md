# Treating `typing.cast()` as a runtime cast

## 1. Catalog record

- **Catalog identifier:** 4.1.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Use `cast()` only to communicate information to a static type checker, not to validate or convert runtime values.

## 2. Example

### 2.1 Scenario

A configuration value must be an integer before being used in arithmetic.

### 2.2 Preferred form

```python
def require_int(value: object) -> int:
    if not isinstance(value, int) or isinstance(value, bool):
        raise TypeError("retry count must be an integer")
    return value


retries = require_int(3)
delay = retries + 1
```

### 2.3 Hazardous form

```python
from typing import cast


raw_value: object = "3"
retries = cast(int, raw_value)
delay = retries + 1
```

### 2.4 Why this difference matters

`cast()` returns the original object unchanged. It can silence a static warning while allowing an incompatible value to fail later during arithmetic.

## 3. Boundaries and distinctions

Use `cast()` after a runtime invariant is already established and the type checker cannot infer it, such as after a checked dispatch branch.
