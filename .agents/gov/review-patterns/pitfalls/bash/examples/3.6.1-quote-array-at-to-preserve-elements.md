# Quote `"${array[@]}"` to preserve elements

## 1. Catalog record

- **Catalog identifier:** 3.6.1
- **Impact:** high
- **Consensus:** high
- **Definition:** Pass all array elements as `"${array[@]}"` so each element remains one argument.

## 2. Example

### 2.1 Scenario

A script forwards user-selected filenames to a processing command.

### 2.2 Preferred form

```bash
files=('quarterly report.csv' '*.backup' '')
printf '<%s>\n' "${files[@]}"
```

### 2.3 Hazardous form

```bash
files=('quarterly report.csv' '*.backup' '')
printf '<%s>\n' ${files[@]}
```

### 2.4 Why this difference matters

Unquoted expansion splits whitespace and expands pathname patterns, while also losing empty elements, so the receiving command gets different arguments.

## 3. Boundaries and distinctions

Use `"${array[*]}"` only when intentionally joining elements into one string with the first character of `IFS`.
