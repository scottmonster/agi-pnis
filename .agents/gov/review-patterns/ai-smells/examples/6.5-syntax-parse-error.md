# Syntax/parse error

## 1. Catalog record

- **Catalog identifier:** 6.5
- **Evidence:** e
- **Definition:** Source text is not valid in the target language and cannot be parsed.

## 2. Scenario

### 2.1 Context

An agent adds a TypeScript guard to an existing request handler.

### 2.2 Safer approach

It runs the project's type-check or formatter after the edit.

### 2.3 Failure mode

It leaves an unmatched brace in the handler and reports the patch complete.

### 2.4 Why this difference matters

The application cannot parse the source, so no behavior can run.

## 3. Boundaries and distinctions

A parse error occurs before static type checking; valid syntax can still have a compile or type-check failure.
